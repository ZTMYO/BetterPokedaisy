游戏进度保存在两类文件中。**游戏存档**是在游戏自己的菜单中保存时写入的标准 `.sav` 或 `.srm` 文件，与 mGBA 和 RetroArch 使用的格式相同，可以在模拟器之间转移。**即时存档**是 PokeDaisy 在任意时刻保存的完整快照，即使在战斗中也能创建。

本页介绍这两类文件，以及 PokeDaisy 如何保护游戏存档。

## 存档保护

PokeDaisy 通过以下方式减少存档丢失：

- **每次启动游戏时备份。** 游戏打开存档前，PokeDaisy 会把存档复制到其旁边的 `pokedaisy-backups` 文件夹。每个游戏保留最近 10 份不同的副本，只有存档发生变化时才新建备份。
- **恢复游戏不会覆盖更新的存档。** 从上次位置继续前，PokeDaisy 会检查存档文件是否已经变化。如果变化了，例如你在 RetroArch 中游玩、复制了其他存档或移动了存档文件夹，应用会暂时搁置旧快照，改从存档文件启动。
- **进行中的保存会完成。** 游戏显示正在保存时，即使通过 HOME、最近使用的应用界面或 `关闭游戏` 离开，PokeDaisy 也会等保存完成再停止游戏，避免立即划掉应用导致存档只写入一半。
- **读取其他存档时保留旧存档。** `读取存档` 会先将当前存档重命名为带日期的副本，再放入新文件。

## 存档位置

游戏按 ROM 文件名查找存档：`Pokemon Emerald.gba` 对应 `Pokemon Emerald.sav` 或 `.srm`。压缩包中的游戏使用包内 ROM 的文件名，与 RetroArch 一样。

PokeDaisy 按以下顺序查找，使用第一个找到存档的位置：

1. **游戏专用存档文件夹**，如果你在游戏库菜单中通过 `存档文件夹` 指定了一个。
2. **存档文件夹**：PokeDaisy 自己的文件夹，或你在向导、设置中选择的文件夹。
3. **`也可查看` 文件夹**，按添加顺序查找。

如果都没有该游戏的存档，第一次保存会写入存档文件夹；如果指定了游戏专用文件夹，则写入专用文件夹。只检查所选文件夹本身，不检查其子文件夹。

### 更改存档文件夹

打开设置 > `文件夹` > `游戏存档`，可以看到当前文件夹及其中的存档：

- `更改文件夹` 选择其他文件夹。
- `使用默认值` 返回 PokeDaisy 自己的文件夹 `Android/data/com.pokedaisy.app/files/saves/`。
- `复制路径` 复制文件夹路径，方便在文件管理器中使用。

更改文件夹不会移动存档。如果希望旧存档出现在新位置，请自行复制。

![文件夹设置页面：分别提供 ROM 文件夹、游戏存档、也可查看和即时存档入口](shots/settings-folders.png "文件夹设置")

### 与 RetroArch 共享存档

如果希望在 RetroArch 和 PokeDaisy 中继续使用同一存档，可在设置 > `文件夹` > `也可查看` 中通过 `添加文件夹` 添加 RetroArch 的存档文件夹。RetroArch 经常为不同核心使用不同文件夹，因此请分别添加，例如 `RetroArch/saves/mGBA` 和 `RetroArch/saves/gpSP`。

在这些文件夹中找到的存档会直接在原位置读取和写入，因此 RetroArch 也能看到最新进度。点击 `移除` 可从列表中移除文件夹。

> [!WARNING]
> 如果存档文件夹和 `也可查看` 文件夹中都有同一游戏的存档，优先使用存档文件夹中的副本。建议每个游戏只保留一个正在使用的副本，避免混淆。

如果通过 Syncthing 等工具在设备之间同步存档，可以让 PokeDaisy 指向同步文件夹。由于只检查文件夹本身，不会处理其子文件夹中的旧副本，例如 Syncthing 的 `.stversions`。

### 为单个游戏指定文件夹

如果只有某个游戏需要使用其他文件夹，例如在另一个模拟器中游玩的改版，可在游戏库中长按该游戏，点击 `存档文件夹` 并选择位置。

如果该文件夹尚无该游戏的存档，应用会把当前存档复制过去；这是复制而非移动，原文件仍在原处。此后该游戏会在新文件夹读取和写入。点击同一菜单中的 `默认存档文件夹` 可恢复使用通常的文件夹。

## 备份和恢复备份

备份保存在存档旁边的 `pokedaisy-backups` 文件夹中，文件名包含游戏名、日期和时间，例如 `Pokemon Emerald.backup-20261007-233512.sav`。备份是否在卸载后保留取决于存档位置：Android 会在卸载应用时删除其应用专属目录，包括默认的 `Android/data/com.pokedaisy.app/files/`。卸载前请将需要保留的存档和备份复制到应用专属目录之外。

要恢复备份，在游戏库中长按游戏并点击 `恢复备份`，按日期和时间选择备份，再点击 `读取` 确认。当前存档会先保存为带日期的副本，因此可以回退。

> [!TIP]
> 金手指可能损坏存档。应用每次启动游戏时都会备份，因此可以恢复到开启金手指之前的存档状态。

## 读取存档文件

要使用来自其他地方的存档，例如其他模拟器的旧存档或朋友的文件，在游戏库中长按游戏并点击 `读取存档`。选择文件后，PokeDaisy 会在你点击 `读取` 确认前说明将要执行的操作：

- 当前存档重命名为旁边的 `<game>.backup-<date and time>`，以保留旧内容。
- 新文件按游戏读取的名称写入。
- 下次启动游戏时，从该存档开始，而不是恢复到上次离开的位置。

如果文件看起来不像 GBA 存档，确认窗口会提示。

## 恢复到上次位置

设置 > `游戏库` 中的 `恢复游戏` 默认开启。关闭游戏时会保存当前时刻的快照，再次启动时直接回到原处，包括道路或战斗中，即使你没有在游戏内保存。

如果希望每次启动都从标题画面开始，再读取游戏内存档，可关闭该选项，行为类似实体卡带。从 HOME 等界面返回仍保持打开的游戏时，仍会从原处继续。

游戏中让设备休眠也可以：游戏停在当前帧，唤醒后从该帧继续，无需重新加载。如果 Android 在休眠时关闭了应用，这相当于关闭游戏；开启 `恢复游戏` 时会从休眠时刻继续。

> [!WARNING]
> 关闭 `恢复游戏` 时，关闭游戏会丢失自上次游戏内保存以来的进度。助手 `设置` 中的 `关闭游戏` 和 `重新启动游戏` 会提醒你。

## 即时存档

即时存档是可以随时创建和读取的快照，例如在困难战斗、捕捉稀有宝可梦或做重要选择之前。

### 即时存档标签页

助手的 `即时存档` 标签页有 10 个槽位，从槽位 0 到槽位 9，每个槽位显示保存时的截图和时间。它默认不在标签栏中：可从齿轮左侧的 `更多` 打开，或通过 `标签栏` 将它加入。

- 槽位下方的 `保存` 将游戏保存到该槽位，替换原内容。
- `读取` 将游戏恢复到该时刻。
- `撤销保存` 恢复最近一次被覆盖槽位的原内容。
- `撤销读取` 回到最近一次读取之前。

标题显示当前槽位，快捷键会向该槽位保存或从中读取。

![即时存档标签页：顶部是撤销保存和撤销读取，下方槽位各有截图、保存和读取按钮](shots/companion-states.png "即时存档标签页")

> [!NOTE]
> 即时存档也包含创建时的游戏存档内容。读取旧即时存档会同时带回当时较旧的游戏存档。如果这不是你想要的，`撤销读取` 可返回读取前的状态；游戏启动时也已创建存档备份。

### 即时存档快捷键

无需打开标签页也可以保存和读取：

| 快捷键 | 默认按键 |
| --- | --- |
| `保存即时存档` | SELECT + R1（键盘 F1） |
| `读取即时存档` | SELECT + L1（F2） |
| `撤销保存` | F3 |
| `撤销读取` | F4 |
| `下一个槽位` | 键盘 ] |
| `上一个槽位` | L3（键盘 [） |

可在设置的 `快捷键` 中修改，见[控制](controls.md)。

即时存档按游戏保存在 `Android/data/com.pokedaisy.app/files/states/`，可在设置 > `文件夹` > `即时存档` 中查看。游戏库中该游戏的 `信息` 会显示已使用槽位数。

## 倒退

走到不想挑战的训练家面前，或选错招式时，开启倒退后可以按住按钮，将最近约 20 秒倒放，然后从任意位置继续。

1. 在上屏或助手设置的 `快进 / 速度` 分组中开启 `倒退`。它默认关闭，因为开启时会使用一些内存和少量电量。
2. 按住 `按住倒退` 快捷键向后倒退，松开后从该处继续。

键盘的 `按住倒退` 默认是 R。手柄默认没有绑定，可在 `快捷键` 中选择，见[控制](controls.md)。倒退时声音静音；到达保留的最早时刻后画面停在那里。

倒退不会修改存档文件：它只让游戏回到过去，游戏内已经保存的内容会保持，直到游戏下次保存。
