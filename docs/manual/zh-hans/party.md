`队伍` 标签页实时显示你的队伍。向下看一眼就能知道谁受伤、中毒或即将升级，无需暂停游戏并打开菜单。

部分汉化游戏使用自己的文字编码。助手会读取已识别版本的队伍名称，包括你取的昵称；无法识别的版本可能无法正确显示。队伍名称包含汉字或日文时，卡片会改用支持这些文字的字体和样式。

## 队伍

每只宝可梦都有一个槽位，显示图标、名称、等级、生命值条以及中毒、睡眠等状态。陷入濒死状态的宝可梦会像游戏中一样改变槽位颜色。在 Game Boy 和 Game Boy Advance 游戏中，这里的名称与游戏队伍界面一样，显示昵称；DS 游戏目前显示宝可梦的种类。SoulGold 的队伍界面会用异色配色显示异色宝可梦，这里的图标也一样。在原版 FireRed、LeafGreen、Ruby、Sapphire 和 Emerald 的各语言版本，以及[异色概率](controls.md#shiny-odds)列出的改版中，异色宝可梦的图标也会在队伍、详情和 HUD 中使用异色配色，尽管游戏自己的队伍界面不这样显示。配色从 ROM 中的战斗配色读取。详情页还会在名称后显示金色闪光，并在图标周围显示金色边框。

携带道具的宝可梦会在槽位右上角显示带有道具图标和名称的小标签，无需逐个打开详情就能查看。游戏本身的小型携带道具标记也会显示在图标旁边。

槽位沿用游戏队伍界面的外观：FireRed 和 Emerald 使用各自的槽位图像，许多改版也有自己的配色。没有专用外观的游戏使用 FireRed 风格的槽位。首次游玩时，图像会从你的 ROM 中重建，因此第一次可能需要片刻才能显示。

![队伍标签页：一只满生命值的宝可梦、一只中毒且生命值较低的宝可梦，以及另外两只队员](shots/companion-party.png "队伍标签页")

图标会像游戏中一样跳动。如果希望图标静止，可在设置的 `调整` 中关闭 `队伍图标动画`。

## 详细信息

点击任一槽位可打开该宝可梦的详情，并占满标签页：

- **左上**：名称、性别（有昵称时，种类显示在昵称后面）、图标、等级、状态、属性、生命值条和经验条。`下一个` 显示升到下一级还需要的经验；100 级时显示 `最大`。
- **左下**：`弱点`、`抵抗` 和 `免疫`，并显示每种属性的倍率，例如 2 倍、½ 倍或 0 倍。这里可以快速看出应让该宝可梦避开什么攻击。
- **右侧**：四个招式及各自的属性、威力和剩余 PP。

![宝可梦详情：左侧显示等级、生命值、经验和属性克制，右侧显示四个招式](shots/companion-summary.png "宝可梦详细信息")

如果宝可梦携带道具，`道具` 一行会显示该道具。在助手支持使用道具的游戏中，点击 `取下` 并确认后，可以把道具放回背包。如果背包没有空间，则显示 `背包已满`，与游戏拒绝操作的情况一致。

底部一排显示队伍中的所有宝可梦，点击其他成员可切换到它的详情。切换时会保留当前页（招式、能力值或学习），方便依次比较全队的个体值。点击右下角蓝色按钮或 `返回` 可回到队伍。

## 能力值：个体值、努力值和性格

点击 `能力值` 可将招式切换为相关数值，包括游戏通常不显示的数据：

- 每项能力的当前数值、**个体值**（0 至 31，达到满值 31 时条形变为金色）和**努力值**，下方显示合计。
- `性格`：被提升的能力用红色标记，被降低的能力用蓝色标记。
- `觉醒力量`：该宝可梦使用此招式时的属性，以及它在 FireRed、Emerald 等原版游戏中的威力。

点击 `招式` 可返回招式页面。

这里显示游戏保存的能力值；游戏只会在升级时重新计算。因此，宝可梦在战斗后刚获得努力值时，某项能力可能比下次升级后低一点。

大多数游戏都有 `能力值` 页面。少数游戏的数据暂时无法可靠读取，因此不显示此页面。

## 学习：哪些招式值得学

点击 `学习` 可查看该宝可梦即将能学会的招式，以及是否建议学习。当前招式移到左侧，右侧列出：

- `后续等级`：之后通过升级学会的招式及对应等级。
- `背包中的招式学习器`：你携带且该宝可梦可以使用的招式学习器和秘传学习器。

每条显示招式属性、威力、命中率、PP 和一项建议：

| 建议 | 含义 |
| --- | --- |
| `学习` | 还有空的招式栏位，建议学习。 |
| `忘记` 加招式名称 | 值得学习，并建议替换掉该招式。 |
| `跳过` | 不比已经掌握的招式更好。 |
| `已学会` | 已经掌握该招式。 |

点击条目可查看原因。原因简短具体，例如新招式能够以 2 倍效果攻击哪些属性、属性一致带来的 1.5 倍加成、命中率为 70%，或招式使用了该宝可梦较弱的攻击能力。建议替换的招式会在左侧显示红色 `忘记` 标签，方便确认将舍弃什么。再次点击条目可关闭。

建议遵循以下规则：

- 新招式必须明显更好才建议替换；提升很小时显示 `跳过`。
- 秘传招式不会被建议遗忘。由于学会后较难移除，只有明显更值得时才建议学习秘传招式。
- 评估会考虑面对各种属性的伤害，而不是只针对一个对手，因此是面向队伍整体的建议，而不是下一场战斗的专用建议。

> [!NOTE]
> `学习` 目前支持原版 FireRed、LeafGreen、Ruby、Sapphire 和 Emerald。改版对招式的修改过多，现阶段尚不能保证建议正确。

这些建议受设置中的 `对战提示` 控制。关闭后，`学习` 仍会列出可学招式和详细信息，但不显示建议和原因。

也可以从另一方向查看：在[背包](bag.md)中选择招式学习器，查看队伍中哪些宝可梦可以学习。
