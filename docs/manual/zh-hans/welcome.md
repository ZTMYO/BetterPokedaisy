PokeDaisy 是一款面向宝可梦游戏的 Android 游戏播放器，支持 Game Boy、Game Boy Color、Game Boy Advance 和 Nintendo DS。游戏旁边运行着实时**助手**，在游玩时读取队伍、背包、当前地图、战斗状况和图鉴，还提供先显示提示、再显示答案的攻略。在 AYN Thor 等双屏掌机上，助手独占下屏；在单屏掌机上，助手以游戏上方的窗口或旁边的面板显示；手机竖屏时则显示在游戏下方。

无需暂停游戏、打开菜单，也能查看宝可梦的招式或攻击对某种属性的效果。这些信息会以游戏菜单的风格显示。

![下屏助手的队伍标签页：六只宝可梦及其等级和生命值条，样式与游戏中的队伍界面一致](shots/companion-party.png "助手的队伍标签页")

## 使用前需要准备

- **Android 8.0 或更新版本的设备。** 可以是双屏掌机、单屏掌机或手机。
- **你自己的游戏。** PokeDaisy 不附带游戏。请使用从自己拥有的卡带中自行提取的 ROM：`.gba` 文件，以及 Game Boy 和 Game Boy Color 的 `.gb` / `.gbc` 文件或 DS 的 `.nds` 文件。文件可以单独放置，也可以放在 `.zip` 或 `.7z` 中。
- **助手支持的游戏。** Game Boy、Game Boy Color、GBA 和 DS 游戏都可以运行，但助手只能读取它支持的作品：FireRed、LeafGreen、Emerald、Ruby、Sapphire、Game Boy 平台的 Red 至 Crystal、DS 平台的 Platinum、HeartGold、SoulSilver 和 Black，以及许多改版。完整列表和确切版本见[支持的游戏](supported-games.md)。

准备好了？[安装与初次设置](install.md)会引导你完成最初的设置。

## 支持哪些设备

PokeDaisy 在 **AYN Thor** 上开发，助手针对其下屏设计。**Retroid Pocket Duo Lite** 较方的下屏有专用布局。其他双屏设备也应能使用；如果设备以下屏作为主显示屏，可以使用 `交换屏幕`。

在单屏设备上，助手以游戏上方的窗口或旁边的面板显示；手机竖屏时，助手停靠在游戏下方。[HUD](hud.md) 可在行走时将队伍、迷你地图和背包显示在游戏画面上；[快捷菜单](controls.md#the-quick-menu)可让你通过一个按钮访问电脑、`飞翔`、自行车、钓竿和即时存档。更多内容见[屏幕与设备](devices.md)。

## 快速导览

**下屏（助手）：**

- [队伍](party.md)：查看队伍的生命值、等级和状态。点击宝可梦可查看详细信息，包括能力、招式、个体值、努力值和之后可学会的招式。
- [背包](bag.md)：查看所有口袋、图标和说明，以及哪些宝可梦可以使用招式学习器。
- [战斗](battle.md)：战斗开始时自动打开。显示招式对对手的效果、对手的弱点、推荐出场的宝可梦，以及战斗或换人的触摸按钮。
- [地图](map.md)：显示你在游戏地区地图上的位置。点击地点或从列表中选择地点，可查看其名称。
- [图鉴](dex.md)：查看宝可梦的进化方式、出现地点和可学招式。
- [攻略](guide.md)：查看当前区域的内容、下一个道馆馆主的队伍，以及遇到困难时的提示。
- [训练家卡片](trainer-card.md)：显示游戏绘制的训练家卡片正反面。
- [成就](achievements.md)：登录后查看 RetroAchievements 成就。
- [助手](companion.md)介绍标签栏、设置以及如何选择显示的标签页。

**上屏（播放器）：**

- [快进与游戏速度](fast-forward.md)：加快重复游玩过程；智能模式会在菜单中减速，并可保持音乐音调。
- [存档、备份和即时存档](saves.md)：十个即时存档槽位、自动存档备份和倒退功能。
- [控制](controls.md)：重新映射按键、设置快捷键、使用手柄或触摸控制。
- [屏幕、画面比例与着色器](screen.md)：使用扩展画面查看更多地图，选择 LCD 和 CRT 外观，并设置状态栏及悬浮层。
- [金手指](cheats.md)：使用 GameShark、Action Replay 和 CodeBreaker 代码。

**应用的其他部分：**

- [游戏库](library.md)：管理游戏、封面、收藏和各游戏的菜单。
- [设置参考](settings-reference.md)：集中查看上下屏的所有设置。
- [疑难解答](troubleshooting.md)：遇到问题时可以尝试的办法。

## 在应用中阅读本手册

本手册可在 PokeDaisy 中打开，无需离开游戏。共有三个入口：

- 在上屏游戏库标题栏中点击 `?` 按钮。
- 在上屏打开设置（游戏库标题栏中的齿轮），然后在 `应用` 分组中选择 `帮助`。
- 在下屏打开助手的 `设置`，然后在列表末尾的 `应用` 分组中选择 `帮助`。

上屏手册有搜索框：输入要查找的内容，例如“快进”“备份”或“重新映射”，即可查看匹配的页面和章节。每个页面末尾都有上一篇和下一篇链接。

简体中文手册随应用附带，可离线阅读；应用联网时也会检查网站上的更新。尚未完成翻译的页面会保留英文并标记“未译”。
