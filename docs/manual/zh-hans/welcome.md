PokeDaisy 是一款面向宝可梦游戏的 Android 游戏播放器，支持 Game Boy、Game Boy Color、Game Boy Advance 和 Nintendo DS。游戏旁边运行着实时**助手**：你在游玩时，它会读取你的游戏，显示队伍、背包、所在的地图、当前战斗的进展、图鉴，还有一份先给提示、再给答案的攻略。在 AYN Thor 这类双屏掌机上，助手独占下屏。在单屏掌机上，助手会以覆盖游戏的窗口或旁边的面板出现，手机竖持时则位于游戏下方。

你不必暂停游戏、打开菜单，就能查看某只宝可梦的招式，或查询某个招式打某种属性的效果。瞥一眼就能看到，而且用的还是游戏自己的菜单风格。

![下屏助手的队伍标签页：六只宝可梦及其等级和生命值条，样式与游戏中的队伍界面一致](shots/companion-party.png "助手的队伍标签页")

## 使用前需要准备

- **一台 Android 设备，系统为 8.0 或更新版本。** 双屏或单屏掌机都行，手机也可以。
- **你自己的游戏。** PokeDaisy 不附带任何游戏。请使用从自己拥有的卡带中自行提取的 ROM：`.gba` 文件（Game Boy 和 Game Boy Color 的 `.gb` / `.gbc` 以及 DS 的 `.nds` 也可以），可以单独存放，也可以放在 `.zip` 或 `.7z` 压缩包里。
- **助手支持的游戏。** 任何 Game Boy、Game Boy Color、GBA 和 DS 游戏都能运行，但助手只会读取它认识的作品：FireRed、LeafGreen、Emerald、Ruby、Sapphire，Game Boy 平台的 Red 到 Crystal，DS 平台的 Platinum、HeartGold、SoulSilver、Black、White、Black 2 和 White 2，以及一长串 ROM 改版（DS 平台的 Origin HeartGold 也在其中）。完整列表和确切版本见[支持的游戏](supported-games.md)。

准备好了？[安装与初次设置](install.md)会带你走完最初的五分钟。

## 支持哪些设备

PokeDaisy 是在 **AYN Thor** 上开发的，助手针对它的下屏排版。**Retroid Pocket Duo Lite** 更方的下屏有自己的一套布局。其他双屏设备应该也能用；如果某台设备的主显示屏是下屏，可以用 `交换屏幕` 来应对。

在单屏设备上，助手会以覆盖游戏的窗口（或游戏旁边的面板）打开；手机竖持时，则是一条停靠在游戏下方的区域。[HUD](hud.md) 会在你行走时把队伍、迷你地图和背包留在游戏画面上，[快捷菜单](controls.md#the-quick-menu)则让电脑、`飞翔`、自行车、钓竿和即时存档都只差一个按键。[屏幕与设备](devices.md)介绍了这些内容。

还有一个面向 New Nintendo 3DS 的早期预览版，是一个把助手放在触摸屏上的自制应用：[在 Nintendo 3DS 上安装](3ds.md)。

## 快速导览

**下屏（助手）：**

- [队伍](party.md)：查看你的队伍，包括生命值、等级和状态。点击一只宝可梦可查看完整详情：能力、招式、个体值和努力值，以及它接下来还能学会哪些招式。
- [背包](bag.md)：查看背包的每个口袋，带图标和说明，还能看到你的哪些宝可梦可以使用某个招式学习器。
- [对战](battle.md)：战斗开始时自动打开。显示你的招式对对手的效果、对手的弱点、最适合派上场的宝可梦，以及用于战斗或换人的触摸按钮。
- [地图](map.md)：显示游戏里的地区地图，并标出你的位置。点击某个地点可查看它的名称，也可以从列表中选择。
- [图鉴](dex.md)：你的宝可梦图鉴，包含每只宝可梦的进化方式、出没地点和能学会的招式。
- [攻略](guide.md)：你所在区域里有什么、下一位道馆馆主的队伍，以及卡关时的提示。
- [训练家卡](trainer-card.md)：游戏绘制的训练家卡正面和背面。
- [成就](achievements.md)：登录后可查看 RetroAchievements。
- [助手](companion.md)介绍了标签栏、`设置` 以及如何选择显示哪些标签。

**上屏（播放器）：**

- [快进与游戏速度](fast-forward.md)：快速刷级，智能模式会在菜单中放慢速度，音乐也能保持音调。
- [存档、备份和即时存档](saves.md)：十个即时存档槽位、自动存档备份和倒退。
- [控制](controls.md)：重新映射按键、设置快捷键、使用手柄或触屏按键。
- [屏幕、画面比例与着色器](screen.md)：用 `扩展画面` 看到更多地图，提供 LCD 和 CRT 外观、状态栏和遮罩。
- [金手指](cheats.md)：GameShark、Action Replay 和 CodeBreaker 代码。

**应用的其他部分：**

- [游戏库](library.md)：你的游戏、封面、收藏，以及每款游戏的菜单。
- [设置参考](settings-reference.md)：两块屏幕上的所有设置，集中在一处。
- [疑难解答](troubleshooting.md)：出问题时可以尝试的办法。

## 在应用中阅读本手册

本手册内置在 PokeDaisy 中，因此无需离开游戏就能查阅。有三个入口：

- 在上屏点击游戏库标题栏中的 `?` 按钮。
- 在上屏打开设置（游戏库中的 `设置`，在左侧或底部），然后在 `应用` 分组中选择 `帮助`。
- 在下屏打开助手的 `设置`，在列表最末尾、`应用` 分组中选择 `帮助`。

上屏的手册有搜索框：输入你要找的内容（例如“快进”“备份”“重新映射”），匹配的页面和章节就会显示出来。每个页面末尾都有上一篇和下一篇的链接。

应用会从 PokeDaisy 网站下载手册并保留一份副本，之后就能离线阅读。它需要联网一次：如果首次打开时连不上网站，应用会给出提示。联网后点击 `重试`。
