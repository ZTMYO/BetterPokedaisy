遇到问题？请从这里开始。如果没有找到答案，请参见[最后一节](#how-do-i-report-a-bug-or-ask-for-a-game)，了解如何联系我们。

## 游戏没有出现在游戏库中

请依次检查：

- **文件夹是否已关联？** 在游戏库点击 `+` > `管理 ROM 文件夹`，或打开设置 > `文件夹` > `ROM 文件夹`，检查游戏所在文件夹或其上级文件夹是否在列表中。如果没有，点击 `添加文件夹`。选择文件夹需要 PokeDaisy 的 Android“所有文件访问权限”；如果系统询问，请允许后再次点击按钮。只支持设备存储或 SD 卡上的文件夹，不支持云端文件夹。
- **是否重新扫描？** 每次打开游戏库时都会查找新游戏。点击游戏库顶部的刷新按钮（圆形箭头）可立即扫描，并查看扫描结果。
- **子文件夹是否太深？** 扫描会向下查找几层，但不会无限深入。请将层级过深的游戏向上移动一两层。
- **文件格式是否支持？** 支持 `.gba`、`.gb`、`.gbc`、`.nds` 文件，也支持 `.zip` 或 `.7z` 中的这些文件。其他压缩格式和光盘镜像无法运行。
- **伴侣面板是否支持该游戏？** 关联文件夹只列出宝可梦游戏：包括受支持的游戏，以及基于 FireRed、LeafGreen、Emerald、Ruby 或 Sapphire 的未知游戏（标记为 `不支持`，仍可尝试）。其他 GBA 或 Game Boy 游戏可通过游戏库的 **+** 按钮添加；添加伴侣面板无法读取的游戏前，PokeDaisy 会询问你。
- **是否隐藏了游戏？** 使用 `隐藏` 隐藏的游戏不会出现在游戏库中。打开设置 > `隐藏的游戏`，点击该游戏旁的 `显示`。

有关文件夹和导入的更多说明，请参见[游戏库](library.md)。

## 伴侣面板显示不支持

游戏能正常运行，但伴侣面板无法识别文件。通常是因为游戏或改版的版本不在支持列表中，或者 ROM 已被修改。使用 [ROM 检查工具](https://pokedaisy.com/compatibility/)了解原因（ROM 留在你的设备上）。

如果游戏基于某个原版 GBA 游戏，PokeDaisy 可能仍会尽力读取，或询问你这是哪个游戏。如果希望得到正式支持，可点击 `请求支持`。详见[支持的游戏](supported-games.md)。

## 伴侣面板一直显示加载中

游戏刚启动时，伴侣面板需要识别游戏并查找数据。原版游戏几乎立即完成，大型改版则可能需要几秒钟检查文件。恢复游戏时，面板先显示上次留下的队伍和背包，稍后换成实时数据。`图鉴`、`攻略` 和 `训练家卡` 需要读取游戏自身的表格，因此最后填充。

如果一直显示加载中：

- 跳过标题画面并进入存档。有些游戏在此之前没有可读取的数据。
- 再等一会儿。如果出现问题，一段时间后加载提示下方会显示简短说明，告诉你正在等待什么。
- 检查游戏是否受支持（见上文）。确认无法读取后，面板会显示 `不支持`，而非一直显示加载中。

## 从旧版更新后存档没有迁移

早期 PokeDaisy 使用不同的应用 ID（Android 识别应用的名称）。修正“Daisey”拼写时，ID 先从 `com.pokedaisey.PokeDaiseyApp` 改为 `com.pokedaisey.app`，再改为 `com.pokedaisy.app`。Android 将它们视为不同应用，因此使用新 ID 的版本初始为空，旧游戏、存档、即时存档和设置仍留在旧应用的位置。

它们并未丢失。迁移方法：

1. 用 USB 将设备连接电脑（Android 11 及更新版本上，大多数文件管理器无法打开这些文件夹）。
2. 在设备存储中找到 `Android/data/com.pokedaisey.app/files/`，或 `Android/data/com.pokedaisey.PokeDaiseyApp/files/`。
3. 将其中的 `roms` 和 `saves` 文件夹复制到新应用的 `Android/data/com.pokedaisy.app/files/`。请先打开一次 PokeDaisy，让该文件夹生成。
4. 打开 PokeDaisy，游戏及其存档应会出现。

如果游戏位于关联的 ROM 文件夹、存档位于你自己的文件夹（如 RetroArch 文件夹），无需复制；在设置 > `文件夹` 中重新关联相同文件夹即可。

确认内容都已迁移后，可以卸载旧应用。

## 游戏没有从上次的位置恢复

打开游戏时，PokeDaisy 通常会精确恢复到上次的位置。恢复前，它会检查存档文件是否在那之后发生变化。如果变化了（例如在 RetroArch 使用同一存档、移动存档文件夹或复制进一个存档），恢复旧位置会用旧存档覆盖较新的存档。因此 PokeDaisy 会暂时保留旧恢复点，改为从存档文件启动，以最新存档为准。

另外两种情况也会从存档启动：

- 设置的 `游戏库` 分组中关闭了 `恢复游戏`。
- 在游戏库的游戏菜单中使用了 `读取存档`；此操作总是从所选存档启动。

> [!TIP]
> 每次启动游戏前，PokeDaisy 都会复制其存档并保留最近十份。如果存档出现问题，可长按游戏并选择 `恢复备份`。参见[存档](saves.md)。

## 快进时音乐变静音

这是 `快进音乐` 的 `保持原速` 模式（默认）正在准备。该模式在游戏加速时以正常速度播放干净的音乐录音，避免音乐加速变尖。首次玩游戏时，录音会从你的 ROM 中逐首制作；某首曲目尚未录好时，快进期间该曲目会保持静音。

继续玩一段时间即可逐渐录完。如果希望始终听到声音，可在任一屏幕的设置中将 `快进音乐` 设为 `同步加速`，播放游戏自身加速后的声音。参见[快进](fast-forward.md)。

## 游戏卡顿或设备发热

在设置的 `屏幕` 分组中开启 `帧率 / CPU` 查看运行情况。正常速度应约为 60。点击读数可查看延迟帧、音频供给不足、电池温度和设备是否降频等详情。

如果低于 60 或出现卡顿：

- 在 `着色器` 下关闭 `平滑`，将 `滤镜` 设为无，然后逐项重新开启。
- 首次以 `保持原速` 的 `快进音乐` 模式玩游戏时，PokeDaisy 会在后台录制音乐，使第二个处理器核心忙碌一段时间。虽然有上限，小型设备仍可能明显发热。选择 `同步加速` 或关闭即可跳过录制。
- 关闭其他后台应用，并检查设备是否开启省电模式。

如果画面流畅但按键响应迟缓，例如选择 `战斗` 后短暂没有反应，可在设置 > `屏幕` > `显示选项` 中开启 `轻量伴侣面板`。参见[低性能设备的轻量伴侣面板](screen.md#light-companion-for-slow-devices)。

## 成就无法解锁

请检查：

- **是否已登录？** 在上屏打开设置 > `RetroAchievements` 登录。伴侣面板无法登录，因为下屏没有键盘。
- **ROM 是否有成就集？** 成就仅适用于 RetroAchievements 网站认识的完全匹配的 ROM。在游戏库长按游戏并打开 `信息`，其中的 RetroAchievements 部分会说明该文件是否有成就集。大多数改版没有。
- **是否开启金手指？** 只要加载了任何金手指，成就就会暂停；关闭后继续。参见[金手指](cheats.md)。
- **仅支持普通模式。** PokeDaisy 在 softcore 模式下获得成就，不支持 hardcore 模式。
- **是否离线？** 没有网络时，PokeDaisy 会在后台持续重试。

详见[成就](achievements.md)。

## 应用无法更新

发现新版本后，PokeDaisy 会下载并打开 Android 安装程序。如果失败：

- **允许安装应用。** 首次安装时 Android 会要求允许 PokeDaisy 安装应用（“安装未知应用”）。允许后返回并再次点击更新。已完成的下载会被复用，无需重新下载。
- **签名相同且版本更新。** 只有新旧应用来自同一来源，Android 才允许覆盖安装。如果你自行构建 PokeDaisy 或从其他来源安装，官方更新无法覆盖。必须先卸载，而卸载会删除 PokeDaisy 自有文件夹中的全部内容，因此请先从 `Android/data/com.pokedaisy.app/files/` 复制出 `saves`，如果导入过游戏也复制出 `roms`。

也可以随时从[发布页面](https://github.com/lidor30/pokedaisy/releases/latest)手动获取最新版，或在设置 > `版本` 中检查更新。

## 伴侣面板出现在错误的屏幕上

如果设备的主屏是下屏，游戏会出现在下方，伴侣面板则在上方。在任一屏幕设置的 `屏幕` 分组中开启 `交换屏幕` 即可交换。参见[屏幕与设备](devices.md)。

如果面板完全从屏幕消失，可能是点击了 `关闭伴侣面板`。点击游戏，然后按 BACK 恢复面板。

## PokeDaisy 会通过网络发送什么？

PokeDaisy 没有自己的账号、广告或跟踪。游戏和存档不会离开设备。它只会为以下用途联网：

- **检查更新。** 打开游戏库或点击 `版本` 时向 GitHub 查询最新发布版本；只有你同意后才下载。
- **手册。**`帮助` 从 PokeDaisy 网站加载本手册，并保留离线阅读副本。
- **封面。** 仅当你在设置 > `封面` 中添加自己的密钥时，才从 SteamGridDB 和 RetroAchievements 获取。查找游戏封面时，向 RetroAchievements 提交 ROM 指纹（MD5；DS 游戏使用 RetroAchievements 的 DS 卡带指纹），绝不提交文件。
- **RetroAchievements。** 仅在你登录时使用。打开游戏库中的游戏 `信息` 时，也会通过 ROM 指纹向 RetroAchievements 查询该 ROM 是否有成就集。
- **崩溃报告。** 仅在开启 `崩溃报告` 后发送；默认关闭，应用会在使用几天后询问一次。报告包含设备型号、Android 版本和应用崩溃的位置。
- **分享尽力匹配结果。** 仅在提示时点击 `分享` 才发送。窗口会列出全部发送值：ROM 的 SHA-1、大小、游戏代码和修订版本，按哪个游戏读取及读取效果，以及应用版本。不含文件名、账号或设备详情。

游戏库用于询问一次支持的游玩时长（参见[支持 PokeDaisy](library.md#supporting-pokedaisy)）也不会离开设备。

`请求支持` 本身不会发送任何信息：它会在浏览器中打开游戏请求表单，你可以在发送前查看。

## 如何报告错误或请求支持游戏？

- **需要帮助，或不确定是否为错误？** 可以在 [PokeDaisy Discord](https://discord.gg/vcmyKZZV5q) 询问，设置 > `DISCORD` 也可打开。这里也欢迎分享想法和聊天。
- **没有 GitHub 账号？** 可通过[反馈页面](https://pokedaisy.com/feedback/)报告错误、请求游戏或提出想法。
- **使用 GitHub：** 在 [Issues](https://github.com/lidor30/pokedaisy/issues) 报告错误，在 [Game requests](https://github.com/lidor30/pokedaisy/discussions/categories/game-requests) 请求游戏，在 [Ideas](https://github.com/lidor30/pokedaisy/discussions/categories/ideas) 分享想法；也可以给他人的想法投票。
- **伴侣面板无法读取游戏：** 面板的“不支持”页面或游戏库中游戏 `信息` 里的 `请求支持` 会填入所需详情。

报告错误时，说明设备、游戏及版本、操作步骤和实际发生的情况很有帮助。不要附上 ROM：文件名和游戏 `信息` 中的 SHA-1 已经足够。
