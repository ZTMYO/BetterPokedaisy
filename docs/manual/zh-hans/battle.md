进入战斗后，助手会变成对战界面：轮到你行动时显示大型触摸按钮，并帮助回答战斗中常见的问题，例如这个招式效果如何、对手弱什么属性，以及应该派谁上场。

已识别的无界 2.1.1.1 新汉化版本会从游戏读取战斗中的宝可梦和招式名称。能够唯一匹配我方队伍时，助手会保留你设置的昵称；无法读取的名称保留原有内容并标记“未译”。

## 对战标签页

战斗开始时，`对战` 标签会出现在标签栏最前面并自动打开。战斗结束后，助手会回到之前使用的标签页。如果希望保持当前页面，可在设置的 `调整` 中关闭 `自动切换至对战`；`对战` 标签仍会出现，可以手动点击。

只有 PokeDaisy 能读取战斗时才会显示该标签。在无法读取战斗的游戏中，助手会保留原来的标签页。

## 行动时的触摸按钮

轮到你行动时，标签页显示类似较后期掌机游戏的按钮布局：上方是大型 `战斗`，下方是 `背包`、`逃跑` 和 `宝可梦`。按钮上方的小球显示己方队伍的生命状态，濒死宝可梦显示灰色；训练家战斗中右侧还会显示对手的队伍。回合之间播放招式时，标签页改为显示 `信息`。

这些按钮代替你操作游戏按键：点击 `战斗` 再选择招式，游戏就会选择该招式。等待游戏响应时，按钮上会显示轻轻摇动的小球，你的其他控制会短暂停止，避免两边操作冲突。

![训练家对战轮到玩家行动：大型战斗按钮，下方是背包、逃跑和宝可梦，顶部显示队伍小球](shots/companion-battle.png "训练家对战中轮到你行动")

各按钮的作用：

- `战斗` 立即打开四个招式。点击招式使用，或点击 `取消` 返回。
- `背包` 在上屏打开游戏自己的背包，请在那里选择道具；助手上的 `返回` 可退出背包。
- `宝可梦` 在助手上打开队伍以更换成员，见[战斗中更换宝可梦](#switching-during-a-battle)。
- `逃跑` 尝试逃跑，并帮你关闭成功逃跑后的提示。

Elite Redux 的战斗菜单没有背包，因此该游戏在 `战斗` 下方并排显示 `逃跑` 和 `宝可梦`，不显示 `背包`。

> [!NOTE]
> 触摸按钮适用于 FireRed、Emerald 和部分改版的单打战斗。其他游戏以及双打战斗请照常使用控制设备；`信息` 和 `建议` 仍可使用。各游戏支持情况见[支持的游戏](supported-games.md)。

## 招式及效果判断

每张招式卡显示名称、属性、威力和剩余 PP，并用文字说明对当前对手的效果：

| 显示 | 含义 |
| --- | --- |
| `效果绝佳 2x` | 效果绝佳；对手的两种属性都弱于该招式时为 `4x`。 |
| `一般效果 1x` | 普通伤害。 |
| `效果不佳 ½x` | 效果不佳。 |
| `无效 0x` | 对对手完全不起作用。 |
| `状态` | 不直接造成伤害的招式。 |
| `没有 PP` | 使用次数已耗尽，无法选择。 |

![招式网格：四个招式各自显示属性、威力、PP 和效果，下方是取消按钮](shots/companion-battle-moves.png "选择招式")

### 一键使用招式

如果希望跳过 `战斗` 这一步，可在设置的助手分组中开启 `一键使用招式`。轮到你行动时，四个招式会直接显示在原来 `战斗` 按钮的位置，`背包`、`逃跑` 和 `宝可梦` 在下方排成一行。点击一次即可同时选择战斗和招式。

![一键使用招式开启后，四张招式卡位于上方，背包、逃跑和宝可梦按钮位于下方](shots/companion-battle-onetap.png "一键使用招式")

## 信息：一页查看对战情况

点击 `信息` 可一览当前战斗。页面左右分栏：己方在左，对手在右。

- **顶部**：场上每只宝可梦的卡片，包括图标、名称、等级、状态、属性和生命值。己方卡片还会提示对手属性对你造成的高倍率效果，例如 `岩石 2x`；如果己方抵抗对手属性，则显示 `抵抗`。
- **左下**：己方招式及其对对手的效果判断。
- **右下**：对手的 `弱点`、`抵抗` 和 `免疫`，最强弱点排在前面。

![信息页面：左侧是己方卡片和招式，右侧是对手卡片和弱点，底部显示对手队伍](shots/companion-battle-info.png "训练家对战的信息页面")

单打战斗中内容无需滚动即可放下；双打战斗中页面可以滚动。

### 对手详情

向下滚动对手一栏可查看更多内容：

- `特性` 和 `携带道具`。
- 战斗中的当前能力值。提升或降低的能力会带有小标记，例如绿色 +2 或红色 -1；命中率和闪避率发生变化后也会显示。
- 对手招式，以及各招式对*己方*宝可梦的效果判断。这里出现效果绝佳表示需要警惕。

点击右下角带角箭头的按钮，可让对手信息占据页面大部分空间。己方缩成包含头像和竖直生命值条的一列，对手信息与招式获得更多空间。再次点击恢复。PokeDaisy 会在下一场战斗保留你的选择。

### 异色对手

面对异色野生宝可梦时，`对战` 标签页右上角会显示金色 `异色` 标记，位置与训练家小球相同。在 `信息` 中，其名称后会显示金色闪光，图标使用异色配色并带金色边框。此功能支持原版 FireRed、LeafGreen、Ruby、Sapphire、Emerald 的所有语言版本，以及[异色概率](controls.md#shiny-odds)列出的改版。

### 对手个体值

对手的个体值、努力值和性格默认隐藏，因为查看这些属于提前获取信息。在设置中开启 `对手个体值` 后，`信息` 页面会出现 `能力值` 按钮：并排显示己方和对手的每项能力、个体值和努力值，以及 `性格` 和 `觉醒力量`。界面与[宝可梦详情中的能力值页面](party.md)相同。

## 对手队伍

训练家战斗中，`信息` 和 `建议` 页底部按顺序显示训练家的整个队伍。已经见过的宝可梦显示图标，濒死后图标变淡；尚未派出的成员显示为球。

点击槽位可查看对应宝可梦，而不只是当前场上的成员。`信息` 和 `建议` 会切换到该成员，槽位出现红框，名称旁显示状态：

- `下一个`：训练家即将派出的成员。训练家宣布换人时，页面会自动切换过去。
- `濒死`：已经击败。
- `后备`：本场战斗中曾出场，目前等待。
- `未见过`：尚未出场。点击球会显示其中的宝可梦；如果不想提前知道，可以不点。

再次点击带框的槽位，即可继续跟随当前战斗。

## 建议：派谁上场、使用什么招式

点击 `建议` 可查看己方全队针对当前对手的排名。顶部一行显示对手等级、属性和生命值；下方显示排名前三的成员，分别标记 `第 1`、`第 2` 和 `第 3`。每项包含宝可梦卡片、最佳招式和该招式的效果；当前在场的成员标记 `已出场`。

排名会考虑每只宝可梦最好且可用的招式对当前对手造成的效果，以及对手属性可能对它造成的伤害。点击底栏中的另一只对手宝可梦，列表会针对它重新排序，方便计划下一次换人。

![建议页面：顶部显示对手，下方列出己方三个推荐成员及各自最佳招式](shots/companion-battle-suggestions.png "对战建议")

## 战斗中更换宝可梦

点击 `宝可梦` 会用游戏自身的队伍槽位铺满标签页，并在下方显示选择提示和 `取消` 按钮。光标从 `建议` 中的首选成员开始，标记为 `最佳`；已经在场的成员标记为 `已出场`。

点击宝可梦即可派它出场。PokeDaisy 会代你操作游戏队伍菜单，并在操作期间暂时保持上屏画面不动，避免菜单快速闪动。濒死的宝可梦、蛋和已经在场的成员不能选择。

游戏要求你选择成员时，例如己方宝可梦濒死后，也会出现同一面板。

Game Boy 游戏也支持此功能，包括 Red、Blue、Yellow、PureRed、PureBlue、Gold、Silver、Crystal、Crystal Clear、Prism 和 Polished Crystal。游戏会询问如何处理选中的宝可梦，PokeDaisy 会替你选择换人选项。

![换人面板：使用游戏队伍槽位，显示最佳、已出场和濒死状态，下方有选择提示及取消按钮](shots/companion-battle-switch.png "选择要派出的成员")

## 单屏上的对战按钮

横向使用单屏设备时，战斗期间屏幕右上角有 `战斗`、`宝可梦` 和 `逃跑` 三个按钮。它们使用游戏画面旁的空间：`画面比例` 设为 `扩展画面` 时是战斗边缘外的背景，设为 `原始` 时是黑边。如果空间较窄，按钮会稍微伸入战斗画面的右上角背景区域。

- `战斗` 带有己方宝可梦图标，点击后会在屏幕右侧按行列出招式，颜色与对战标签页的卡片一致。每行显示名称、剩余 PP、属性和威力；开启 `对战提示` 时还显示对当前对手的效果。点击可使用，PP 耗尽的招式不能选择。
- `宝可梦` 在右侧显示类似游戏队伍列表的成员：图标叠在球上并像游戏中一样动画，旁边有名称、等级或状态，以及生命值条。`最佳` 标记建议页面的首选成员并高亮显示，`已出场` 标记当前在场成员。点击可派出。
- `逃跑` 尝试逃跑。训练家战斗不能逃跑，因此按钮变灰。

若不想选择，可点击列表外部或下方的 `取消` 关闭。按钮外观与对战标签页一致，战斗演出时会变暗；战斗开始时从右侧滑入，列表打开或游戏自身的队伍、背包界面显示时滑出。它们只在支持触摸按钮的游戏的单打战斗中、游戏旁有空间时显示；`画面比例` 设为 `拉伸` 或助手锁定在游戏旁时不显示。要隐藏它们，可在上下屏设置的屏幕分组中关闭 `对战按钮`。

## 关闭提示

如果希望自己判断属性相克，可在设置中关闭 `对战提示`。招式效果判断、对手弱点、己方卡片警告和 `最佳` 标记都会隐藏；生命值、属性、等级、招式、威力和 PP 等事实仍会显示。需要时仍可打开 `建议`。
