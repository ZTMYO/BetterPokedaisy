打开 PokeDaisy 后首先看到的就是游戏库：所有已添加的游戏，按你选择的顺序排列。点击游戏即可开始游玩。

第一次运行大型游戏（例如 DS 游戏或 `.zip` 中的游戏）时，PokeDaisy 会先完整读取它，这可能要花几秒钟。读取期间游戏库会变暗，屏幕中央有一颗红白小球来回摇动，直到游戏打开；此时其他内容都无法点击。

| 按钮 | 功能 |
| --- | --- |

| 搜索 | 按游戏名称或文件名查找游戏（见[搜索](#searching)）。 |

## 游戏、工具和设置

游戏库左侧边缘有三个按钮：`游戏`、`工具` 和 `设置`。手机竖持时，它们会移到屏幕底部的一条栏中。无论打开哪一页，这三个按钮都始终显示，旁边的页面会随之切换。

- `游戏` 就是你的游戏库，包含游戏及其上方的快捷视图。
- `工具` 会在原本显示游戏的位置，显示 PokeDaisy 除了游玩还能对你的游戏做些什么。点击一项即可打开。工具页的顶部只有帮助按钮，因为排序和添加只用于游戏。
- `设置` 会在同一位置显示设置页，就在游戏库顶部按钮的下方。在设置中的任意页面再次点击 `设置` 可回到第一页，从那里按 `BACK` 则返回游戏。

| 工具 | 功能 |
| --- | --- |
| `给 ROM 打补丁` | 将 `.bps` 补丁变成游戏（见[为 ROM 改版打补丁](#patch-a-rom-hack)）。 |
| `联机游玩` | 像用连接线一样将两到四款 GBA 游戏连接起来，在它们之间交换和对战（见[联机游玩](link-play.md)）。 |
| `存档编辑器` | 打开游戏存档：整理电脑、修改背包、金钱和招式（见[存档编辑器和交换存档](save-trade.md)）。 |
| `交换存档` | 在两个游戏的存档文件之间交换宝可梦（见[存档编辑器和交换存档](save-trade.md)）。 |

`工具` 上的绿点表示其中有一个是新工具。工具页上的 `BACK` 会带你返回游戏。

![打开的工具页面：每个工具一张卡片，显示图标、名称和一行功能说明](shots/library-tools.png "工具")

## 添加游戏

有三种方式可以将游戏加入游戏库。选择适合你的方式即可，它们可以混合使用。以补丁形式提供的 ROM 改版可通过[为 ROM 改版打补丁](#patch-a-rom-hack)变成游戏。

### 关联 ROM 文件夹

如果你的游戏已经放在文件夹中，这是最简单的方法。可以在初次设置中关联，也可以在游戏库中选择 `+` > `添加 ROM 文件夹`，或在设置 > `文件夹` > `ROM 文件夹` 中选择 `添加文件夹`。

- 可以关联任意数量的文件夹。只关联存放游戏的那些文件夹（例如 `ROMs/gba`、`ROMs/gbc` 和 `ROMs/nds`）比扫描一个包含所有主机游戏的大文件夹更快。
- 其中每个受支持的游戏都会出现在游戏库中。
- 游戏直接从原位置运行，不会复制，因此不占用额外空间。
- 每次返回游戏库时都会检查文件夹中是否有新游戏。`ROM 文件夹` 中的 `重新扫描` 或刷新按钮可立即检查。
- `+` > `管理 ROM 文件夹` 会打开已关联文件夹列表，并显示每个文件夹中有多少款游戏。`移除` 会将该文件夹中的游戏移出游戏库，你的文件仍留在原处。
- 已关联文件夹中的子文件夹已被包含，因此不会重复添加。如果关联一个包含之前已关联文件夹的上级文件夹，它会取代那些文件夹。

关联文件夹中的游戏是你自己的文件，因此游戏库绝不会删除它们。它们的菜单显示 `隐藏` 而不是 `删除`。

### 使用 + 导入

点击顶部的 `+`，选择 `添加 ROM 文件`，然后选择一个游戏文件。PokeDaisy 会将其复制到应用自己的游戏文件夹中，并加入游戏库。如果文件是压缩包，导入时会解压。

如果伴侣面板无法读取该游戏，应用会提示 `不支持`，并询问是否仍要添加：游戏仍可游玩，只是伴侣面板不会显示其队伍、地图、道具或战斗。

### 将文件复制到应用文件夹

直接复制到设备上的 `Android/data/com.ztmyo.betterpokedaisy/files/roms/` 中的游戏（使用文件管理器或从电脑复制）也会显示。复制后请在游戏库中点击刷新。

### 为 ROM 改版打补丁

大多数 ROM 改版以 `.bps` 补丁的形式提供：这种文件会把你已有的游戏变成该改版。PokeDaisy 可以替你应用补丁。

1. 点击 `+` 并选择 `给 ROM 打补丁`（它也在 `工具` 中），然后选择 `.bps` 文件。使用 `添加 ROM 文件` 选择 `.bps`，或从文件管理器用 PokeDaisy 打开它，效果相同。
2. PokeDaisy 会读取补丁，并在你的游戏库中查找它对应的原版游戏。补丁通过校验和（CRC32，即每个字节的指纹）来指定该游戏，因此无论文件叫什么名字都能找到正确的文件，压缩包中的也不例外。你不需要自己挑选。
3. 找到后，你会看到补丁、要打补丁的游戏以及打补丁后的游戏将保存到哪里。点击 `应用补丁`，进度条会显示进度。
4. 完成后，应用会告诉你新游戏的位置。如果伴侣面板能读取它，它会立即出现在游戏库中，点击 `开始游戏` 即可启动。

你的原版游戏绝不会被修改：打补丁后的游戏是一个新文件，以补丁命名（`My Hack.bps` 会生成 `My Hack.gba`）。它会和其他同类游戏放在一起：优先放入名为 `gba`、`gb`、`gbc` 或 `nds` 的已关联文件夹；否则放入原版游戏所在的文件夹；再否则放入 PokeDaisy 自己的游戏文件夹。如果该名称的文件已存在，新文件会加上编号（`My Hack (2).gba`）；如果之前已经生成过一模一样的打补丁游戏，则直接保留原来的文件。

如果看到 `未找到基础 ROM`，说明你的游戏中没有补丁所需的校验和。如果 PokeDaisy 知道所需的是哪个游戏（某个确切版本，例如 FireRed 的第一版或第二版），提示中会说明。将该游戏加入游戏库或 ROM 文件夹，然后重试。大多数改版需要干净、未经修改的美版 FireRed 或 Emerald：已经打过补丁，或语言、版本不同的游戏，校验和会不同。

如果伴侣面板不支持打补丁后的游戏，应用会提示，并且它不会加入游戏库，但文件仍会保存。`请求支持` 可申请添加该游戏。如果它保存在 PokeDaisy 自己的游戏文件夹中，设置 > `隐藏的游戏` 仍可在游戏库中显示它。

### 文件类型

- `.gba` 文件，以及 Game Boy / Game Boy Color 的 `.gb` 和 `.gbc` 文件。
- `.zip` 或 `.7z` 压缩游戏。在 ROM 文件夹中它们保持压缩：游玩时 PokeDaisy 会从压缩包中读取游戏。压缩游戏的存档以压缩包内的游戏命名，与 RetroArch 的做法相同。

## 游戏名称

PokeDaisy 能识别受支持的游戏，并显示其正确名称（如“Pokémon FireRed”“Pokémon Unbound”），无论文件叫什么。其他游戏显示整理后的文件名：像 `(USA, Europe)` 这样的转储标签和编号会被去掉。

想给游戏换个名字，可使用其菜单中的 `重命名`。它只更改游戏库显示的名称；文件本身仍保留原名，因此存档仍能被找到。

更喜欢使用自己的文件名？请在设置中的 `游戏库` 分组里将 `游戏名称` 设为 `文件名`。

## 搜索

点击顶部的搜索按钮并开始输入。窗口后面的游戏会随输入内容筛选，可按游戏库显示的名称或文件名匹配。大小写和重音符号不影响结果，词序也可以任意，因此 `red fire` 能找到 FireRed。

点击 `完成` 查看剩余结果，搜索框会留在列表顶部。点击那里的 `清除` 或按 BACK 可再次看到所有游戏。

## 排序与收藏

点击排序按钮，在 `排序方式` 下选择：

- `名称`：按 A 到 Z 排序。
- `上次游玩`：最近玩过的游戏排在最前。从前端启动的游戏也会计入。
- `添加日期`：最新加入的游戏排在最前。

无论采用哪种顺序，收藏的游戏总是排在最前。要将游戏设为收藏，打开其菜单并点击顶部的 `收藏`；名称旁会出现一颗金星。`取消收藏` 可将其移除。

过去 24 小时内出现的游戏会带有绿色 `新` 标签。在设置 PokeDaisy 时（或关联文件夹时）已在游戏库中的游戏不会获得该标签，因此它只标记真正新加入的游戏。

设备竖持时，或菜单高度超出屏幕时，菜单会分成两列。

## 隐藏的游戏

`隐藏` 适用于你想暂时收起来的游戏，例如已通关的改版或重复的游戏。游戏会从游戏库中消失，但其名称、封面和存档都会保留。

要恢复游戏，打开设置 > `隐藏的游戏` 并点击该游戏（`显示`），或点击 `显示全部`。

## 封面

封面来自两个免费服务，每项你想使用的服务都需要你自己的免费密钥。可在初次设置或设置 > `封面` 中添加：

- `RetroAchievements WEB API 密钥`：为每个有成就集的游戏提供方形封面。会优先尝试。
- `SteamGridDB API 密钥`：为 FireRed、Emerald 和受支持的改版提供图标，在 RetroAchievements 没有封面时使用。

点击任一服务旁的 `获取密钥` 打开密钥所在页面，复制密钥，粘贴到输入框并点击 `保存`。PokeDaisy 会为每款游戏获取一次封面并保存在设备上。`全部替换` 会为所有游戏重新获取封面，替换现有封面（包括你自己选择的封面）。`清除` 会移除密钥。

没有封面的游戏会以自身颜色的像素字母显示游戏类型：Game Boy 游戏显示 `GB`（灰色），仅 Game Boy Color 游戏显示 `GBC`（黄色），Game Boy Advance 游戏显示 `GBA`（紫色），DS 游戏显示 `NDS`（蓝绿色），ROM 改版显示 `HACK`（红色）。

### 选择其他封面

不喜欢游戏得到的封面？打开其菜单并点击 `替换封面`。选择器会显示为游戏找到的所有图标；点击即可使用。如果没有按名称找到游戏，请在搜索框中输入其他名称并点击 `搜索`。选择器需要已保存的密钥才能找到内容。

![替换封面选择器：搜索框下方是封面图标网格，每个图标都显示上传者名称](shots/library-cover-picker.png "选择封面")

要改用你自己的图片，点击菜单中的 `设置封面`，然后从设备中选择一张图片。

## 双屏启动器

在双屏设备上，游戏库专为实体按键设计。它仍是同一个游戏库：左侧是 `游戏`、`工具` 和 `设置`（见[游戏、工具和设置](#games-tools-and-settings)），顶部是[快捷视图](#quick-views)，下方以列表或网格显示当前视图的游戏（顶部视图按钮可切换），每行都会显示文件所在位置。

方向键会在其中移动光标：上下移动一行，左右沿网格的一行移动。从列表顶部向上可到达快捷视图：左右切换视图，按下、A 或 B 返回游戏。再向上一次可到达顶部按钮（排序、视图、导入等）；按 A 选择按钮，按下或 B 返回。从顶部第一个按钮、第一个快捷视图或网格第一列向左可到达 `游戏`、`工具` 和 `设置`：上下选择，按 A 打开，按右或 B 返回。在 `工具` 上，方向键在工具之间移动，按 A 打开，按 B 或 `BACK` 返回游戏。L 和 R 翻页。角落的小图例会提示其余按键：

- **A** 打开游戏。
- **B** 打开游戏菜单（与长按相同）。无论某个选项打开什么，例如 `信息`，按 B 都会返回菜单。
- **Y** 打开设置。

屏幕竖持时，图例会浮在 `游戏`、`工具` 和 `设置` 栏的上方，因此绝不会遮住它们。

使用触摸屏时，点击游戏会立即打开，长按则会打开其菜单。

如果更喜欢没有光标和图例的游戏库，请在设置中的 `游戏库` 分组里关闭 `双屏启动器`。

## 游戏信息

游戏菜单中的 `信息` 会分区显示 PokeDaisy 对该游戏的了解：

- **游戏**：游戏名称、被识别为哪个游戏、伴侣面板是否支持（`第二屏幕`）、上次游玩时间以及封面来源。
- **ROM**：文件、所在文件夹、来源、大小以及文件头中的游戏代码。
- **存档文件**：存档所在位置（游戏首次存档前则显示将保存到的位置）以及备份数量。
- **即时存档**：10 个槽位中已使用了几个、最新的即时存档以及恢复状态。
- **RetroAchievements**：游戏是否有成就集；如果已登录，还会显示你已获得的成就数量。

对于伴侣面板不支持的游戏，`请求支持` 会在 PokeDaisy 网站上打开游戏申请，并预填文件名、大小和指纹。ROM 本身绝不会发送。

## 支持、部分支持与不支持

所有游戏都能游玩，但伴侣面板只读取它认识的游戏。游戏库会为其余游戏添加标记：

- `不支持`：游戏可以游玩，伴侣面板会显示提示，而不是其标签页。
- `部分支持`：PokeDaisy 将 ROM 匹配到了它认识的游戏。队伍、背包、地图和战斗可用，未匹配的部分会关闭。

对于关联文件夹，游戏库会列出受支持的游戏，以及所有基于 FireRed、LeafGreen、Emerald、Ruby 或 Sapphire 的未支持改版（带标记），供你尝试。当 PokeDaisy 无法判断 ROM 基于哪款游戏时，`信息` 中提供 `选择游戏` 来告知，以及 `清除匹配` 来撤销匹配。[支持的游戏](supported-games.md) 中有完整列表，并说明了匹配原理。

在设置的 `游戏库` 分组中开启 `仅显示支持的游戏`，伴侣面板无法读取的游戏就不会出现在游戏库中。

## 支持 PokeDaisy

PokeDaisy 免费、无广告，由一个人制作。游玩较长时间后，游戏库会询问一次是否愿意支持它，并提供 `BUY ME A COFFEE`、`PATREON` 和 `KO-FI`。选择其中一项后，浏览器会打开相应页面。`稍后提醒`（或按 BACK）会在再游玩几小时后再次询问，`不用了` 则表示不再询问。选择某个网站也算作已回答。

为判断何时询问，PokeDaisy 会统计游戏的运行时长。该统计只保留在你的设备上，绝不会发送到任何地方。

## 使用方向键或手柄

无需触摸屏幕也能操作游戏库。用方向键移动；选中的游戏或按钮会出现橙色边框。从游戏列表顶部一行向上可到达快捷视图，再向上可到达顶部按钮。

## 从前端启动

如果你使用 **ES-DE**、**iiSU** 或 **Cocoon** 等前端浏览所有游戏，它可以直接在 PokeDaisy 中启动游戏，跳过游戏库。退出游戏时（长按 `BACK` 或使用退出快捷键），你会回到前端。

Cocoon 已经知道如何用 PokeDaisy 运行 GBA、Game Boy、Game Boy Color 和 DS 游戏，压缩游戏也不例外。如果没有出现这个选项，或 Cocoon 对压缩游戏显示 `Incompatible Player`，请在 Cocoon 的设置中刷新平台（位于 Library & Data 下），然后选择 PokeDaisy 作为播放器。

在其他前端中，请为每个系统将 PokeDaisy 添加为自定义或独立模拟器，并填写以下值：

| 字段 | 值 |
| --- | --- |
| Package | `com.pokedaisy.app` |
| Activity | `com.ztmyo.betterpokedaisy/com.pokedaisy.app.LaunchActivity` |
| Action | `android.intent.action.VIEW` |
| Data | ROM（前端的 ROM 占位符） |

有几点需要了解：

- 授予所有文件访问权限后，游戏会直接从前端保存的位置运行。否则会先复制一次到 PokeDaisy 的游戏文件夹，之后复用。
- 与平时一样，游戏会按 ROM 文件名在你的存档文件夹中查找存档。要与前端模拟器共享存档，请在设置 > `文件夹` 中添加其存档文件夹（见[存档、备份和即时存档](saves.md#where-your-saves-live)）。
- 游戏运行时从前端启动另一款游戏会切换过去，当前游戏会先挂起。

分步指南见 [ES-DE](https://github.com/lidor30/pokedaisy/blob/main/docs/es-de/README.md) 和 [iiSU](https://github.com/lidor30/pokedaisy/blob/main/docs/iisu/README.md)。
