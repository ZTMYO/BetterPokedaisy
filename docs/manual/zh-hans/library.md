打开 PokeDaisy 后首先看到的是游戏库：所有添加的游戏按你选择的顺序排列。点击游戏即可开始游玩。

![列表视图中的游戏库：顶部有排序、视图、添加、刷新、帮助和设置按钮，其下是彩色快捷视图及游戏列表](shots/library-list.png "列表视图中的游戏库")

顶部按钮从左到右依次是：

| 按钮 | 功能 |
| --- | --- |
| 排序 | 选择游戏顺序（见[排序与收藏](#sorting-and-favorites)）。 |
| 列表／网格 | 切换列表（每行一个游戏，显示文件路径）和封面网格。 |
| `+` | 添加游戏：`添加 ROM 文件`、`添加 ROM 文件夹` 或 `管理 ROM 文件夹`（见[添加游戏](#adding-games)）。 |
| 刷新 | 再次扫描 ROM 文件夹并显示结果。 |
| `?` | 打开本手册。 |
| 齿轮 | 打开设置。 |

正在运行的游戏显示 `正在游玩`；名称旁的小存档图标表示该游戏有存档文件。

## 快捷视图

顶部下方的一排彩色按钮将游戏库筛选为某一类。点击只显示该类游戏；当前视图的按钮会填充颜色。按钮上的数字表示游戏数量。

| 视图 | 显示内容 |
| --- | --- |
| `全部` | 所有游戏。 |
| `收藏` | 标星的游戏（见[排序与收藏](#sorting-and-favorites)）。 |
| `最近` | 所有玩过的游戏，最近玩过的排在最前，不受排序方式影响。 |
| `GB` | Game Boy 游戏，如 Red、Blue 和 Yellow。 |
| `GBC` | Game Boy Color 游戏，如 Crystal，以及也能在 Game Boy 运行的 Gold 和 Silver。 |
| `GBA` | Game Boy Advance 游戏。 |
| `DS` | Nintendo DS 游戏。 |
| `改版` | ROM 改版。 |

主机视图和 `改版` 使用与没有封面游戏相同的颜色（见[封面](#cover-art)）；游戏库中有对应游戏时才显示。改版同时出现在 `改版` 和对应主机视图中，例如 FireRed 改版也会出现在 `GBA` 中。

![打开的 GBC 快捷视图：按钮填充黄色条纹，列表只显示 Game Boy Color 游戏](shots/library-views.png "快捷视图")

关闭应用后，游戏库仍会记住所选视图。空视图会提示如何添加游戏。

## 添加游戏

游戏可通过以下三种方式添加，可混合使用。

### 关联 ROM 文件夹

如果游戏已经放在文件夹中，这是最简单的方法。可在初次设置中关联，也可在游戏库选择 `+` > `添加 ROM 文件夹`，或在设置 > `文件夹` > `ROM 文件夹` 中选择 `添加文件夹`。

- 可关联任意数量的文件夹。只关联存放游戏的文件夹（例如 `ROMs/gba`、`ROMs/gbc` 和 `ROMs/nds`），比扫描包含所有系统游戏的大文件夹更快。
- 文件夹中每个受支持的游戏都会出现在游戏库中。
- 游戏直接从原位置运行，不会复制，也不占额外空间。
- 每次返回游戏库时都会检查新游戏。`ROM 文件夹` 中的 `重新扫描` 或刷新按钮可立即检查。
- `+` > `管理 ROM 文件夹` 打开已关联文件夹列表，显示各文件夹的游戏数量。`移除` 会将该文件夹的游戏移出游戏库，文件仍留在原处。
- 已关联文件夹中的子文件夹已包含在内，不会重复添加。关联一个包含之前已关联文件夹的上级文件夹时，上级会取代它们。

关联文件夹中的游戏属于你自己的文件，游戏库不会删除；其菜单显示 `隐藏` 而非 `删除`。

### 使用 + 导入

点击顶部 `+`，选择 `添加 ROM 文件` 并选择游戏文件。PokeDaisy 会将其复制到应用自己的游戏文件夹并加入游戏库。如果文件已压缩，导入时会解压。

如果伴侣面板无法读取，应用会提示 `不支持` 并询问是否仍要添加：游戏仍能运行，只是面板无法显示队伍、地图、道具或战斗。

### 复制文件到应用文件夹

直接将游戏复制到设备的 `Android/data/com.pokedaisy.app/files/roms/`（使用文件管理器或电脑），游戏也会显示。复制后请点击游戏库中的刷新按钮。

### 文件类型

- `.gba`，以及 Game Boy／Game Boy Color 的 `.gb` 和 `.gbc`。
- `.zip` 或 `.7z` 压缩的游戏。在 ROM 文件夹中它们保持压缩；游玩时 PokeDaisy 从压缩包读取游戏。压缩游戏的存档以包内游戏命名，与 RetroArch 相同。

## 游戏名称

PokeDaisy 可识别受支持的游戏，并显示正确名称（如“Pokémon FireRed”“Pokémon Unbound”），不受文件名影响。其他游戏显示整理后的文件名：移除 `(USA, Europe)` 等转储标签和编号。

要使用其他显示名称，可在游戏菜单中选择 `重命名`。它只更改游戏库显示的名称，不改变文件名，因此仍能找到存档。

## 排序与收藏

点击排序按钮，在 `排序方式` 下选择：

- `名称`：按字母 A 到 Z 排序。
- `上次游玩`：最近玩过的游戏排在最前，包括从前端启动的游戏。
- `添加日期`：最近添加的游戏排在最前。

无论排序方式如何，收藏游戏总在最前。打开游戏菜单并点击顶部 `收藏`，名称旁会出现金星；`取消收藏` 可移除。

最近 24 小时出现的游戏带有绿色 `新` 标签。设置 PokeDaisy 或关联文件夹时已在库中的游戏不会获得该标签，因此它只标记真正新加入的游戏。

## 游戏菜单

在列表或网格中长按游戏可打开菜单。列表视图中也可点击行末的三个点。

![游戏库上打开的游戏菜单，包含收藏、信息、重命名、封面、存档、金手指、隐藏和删除选项](shots/library-menu.png "游戏菜单")

| 选项 | 功能 |
| --- | --- |
| `收藏`／`取消收藏` | 用金星将游戏置于游戏库顶部，或取消收藏。 |
| `信息` | 查看游戏、存档和即时存档的详细信息（见[游戏信息](#game-info)）。 |
| `重命名` | 修改游戏库显示的名称。 |
| `替换封面` | 打开封面选择器（见[封面](#cover-art)）。 |
| `设置封面` | 使用设备上的图片作为封面。 |
| `重置封面` | 恢复自动封面；仅在自行选择封面后显示。 |
| `读取存档` | 将另一个存档文件放入游戏，当前存档会保留为带日期的副本。 |
| `恢复备份` | 恢复自动存档备份之一。 |
| `存档文件夹` | 为此游戏指定独立存档文件夹，例如其他模拟器的存档文件夹。 |
| `默认存档文件夹` | 恢复通常的存档文件夹，仅在设置过 `存档文件夹` 后显示。 |
| `金手指` | 在设置中打开该游戏的金手指代码。参见[金手指](cheats.md)。 |
| `隐藏` | 从游戏库移除游戏，不改动文件。 |
| `删除` | 删除游戏文件，保留存档和即时存档。仅适用于导入的游戏，绝不删除关联文件夹中的游戏。 |

有关 `读取存档`、`恢复备份` 和 `存档文件夹`，参见[存档、备份和即时存档](saves.md#load-a-save-file)。

如果菜单高度超出屏幕，会分成两列。

## 隐藏的游戏

`隐藏` 用于暂时移除不想看到的游戏，例如已完成的改版或重复游戏。游戏从库中消失，但名称、封面和存档都会保留。

要恢复游戏，打开设置 > `隐藏的游戏` 并点击游戏（`显示`），或点击 `显示全部`。

## 封面

封面来自两个免费服务，每个想使用的服务都需要你自己的免费密钥。可在初次设置或设置 > `封面` 中添加：

- `RetroAchievements WEB API KEY`：提供所有有成就集游戏的方形封面，优先尝试。
- `SteamGridDB API KEY`：提供 FireRed、Emerald 和受支持改版的图标，在 RetroAchievements 没有封面时使用。

点击对应服务旁的 `获取密钥` 打开密钥页面，复制后粘贴到输入框并点击 `保存`。PokeDaisy 为每个游戏获取一次封面并保存在设备上。`全部替换` 会为所有游戏重新获取封面，替换已有封面（包括自行选择的封面）；`清除` 会移除密钥。

没有封面的游戏会在对应颜色上用像素字母显示类型：Game Boy 的 `GB`（灰色）、仅限 Game Boy Color 的 `GBC`（黄色）、Game Boy Advance 的 `GBA`（紫色）、DS 的 `NDS`（蓝绿色）或 ROM 改版的 `HACK`（红色）。

### 选择其他封面

不喜欢自动获取的封面？打开游戏菜单并点击 `替换封面`。选择器显示找到的所有图标，点击即可使用。按名称找不到游戏时，可在搜索框输入其他名称并点击 `搜索`。选择器需要已保存的密钥才能查找。

![替换封面选择器：搜索框下方是封面图标网格，每个图标显示上传者名称](shots/library-cover-picker.png "选择封面")

要使用自己的图片，可在菜单中点击 `设置封面`，然后选择设备上的图片。

## 双屏启动器

在双屏设备上，游戏库针对实体按键设计，但仍是同一个游戏库：顶部是[快捷视图](#quick-views)，下方以列表或网格显示当前视图的游戏（顶部视图按钮可切换），各行显示文件位置。

方向键移动光标：上下移动行，在网格一行内左右移动。从列表顶部再向上可到达快捷视图：左右切换视图，按下、A 或 B 返回游戏。从这里再向上可到达顶部按钮（排序、视图、导入等）；A 按下按钮，下或 B 返回。L 和 R 翻页。角落的小提示说明其余按键：

- **A** 打开游戏。
- **B** 打开游戏菜单（与长按相同）。无论选项打开什么，例如 `信息`，B 都会返回菜单。
- **Y** 打开设置。

使用触摸屏时，点击游戏立即打开，长按打开菜单。

如果希望游戏库不显示光标和按键提示，可在设置的 `游戏库` 分组中关闭 `双屏启动器`。

## 游戏信息

游戏菜单中的 `信息` 分区显示 PokeDaisy 对该游戏的了解：

- **游戏**：名称、识别为哪个游戏、伴侣面板是否支持（`第二屏幕`）、上次游玩时间及封面来源。
- **ROM**：文件、文件夹、来源、大小及文件头中的游戏代码。
- **存档文件**：存档位置（首次存档前显示将使用的位置）和备份数量。
- **即时存档**：10 个槽位中已使用的数量、最新即时存档及恢复状态。
- **RetroAchievements**：游戏是否有成就集；登录后还显示已获得的成就数量。

对伴侣面板不支持的游戏，`请求支持` 会打开 PokeDaisy 网站的游戏请求表单，预填文件名、大小和指纹。ROM 本身绝不会发送。

## 支持、部分支持与不支持

所有游戏都能运行，但伴侣面板只能读取它认识的游戏。游戏库会为其余游戏标记：

- `不支持`：游戏可以运行，伴侣面板显示提示而非标签内容。
- `部分支持`：PokeDaisy 将 ROM 匹配到了已知游戏。队伍、背包、地图和战斗可用，未匹配的内容会关闭。

关联文件夹中，游戏库会列出受支持的游戏，以及所有基于 FireRed、LeafGreen、Emerald、Ruby 或 Sapphire 的未支持改版（带标记），供你尝试。PokeDaisy 无法判断 ROM 基于哪个游戏时，可在 `信息` 中通过 `选择游戏` 告知，或通过 `清除匹配` 撤销匹配。完整列表及匹配原理见[支持的游戏](supported-games.md)。

## 支持 PokeDaisy

PokeDaisy 免费、无广告，由一人制作。游玩较长时间后，游戏库会询问一次是否愿意支持，提供 `BUY ME A COFFEE`、`PATREON` 和 `KO-FI`。选择后浏览器会打开相应页面。`稍后提醒` 或 BACK 会在再玩几小时后重新询问；`不用了` 表示不再询问。选择网站也算作已回答。

为判断何时询问，PokeDaisy 会统计游戏运行时间。该统计只留在设备上，不会发送到任何地方。

## 使用方向键或手柄

无需触屏也可操作游戏库。用方向键移动，选中的游戏或按钮会出现橙色边框。在游戏顶部一行向上可到达快捷视图，再向上可到达顶部按钮。

## 从前端启动

如果使用 **ES-DE**、**iiSU** 或 **Cocoon** 等前端浏览全部游戏，可以让前端直接在 PokeDaisy 中启动 GBA 游戏，跳过游戏库。退出游戏时（长按 `BACK` 或使用退出快捷键）会返回前端。

在前端将 PokeDaisy 添加为 GBA 的自定义或独立模拟器，填写：

| 字段 | 值 |
| --- | --- |
| Package | `com.pokedaisy.app` |
| Activity | `com.pokedaisy.app.LaunchActivity` |
| Action | `android.intent.action.VIEW` |
| Data | ROM（前端的 ROM 占位符） |

注意：

- 授予所有文件访问权限后，游戏直接从前端保存的位置运行；否则会复制一次到 PokeDaisy 的游戏文件夹，之后复用。
- 与平时一样，按 ROM 文件名在存档文件夹中查找存档。要与前端模拟器共享存档，可在设置 > `文件夹` 中添加其存档文件夹（见[存档、备份和即时存档](saves.md#where-your-saves-live)）。
- 游戏运行时从前端启动另一个游戏会切换过去，当前游戏会先挂起。

[ES-DE](https://github.com/lidor30/pokedaisy/blob/main/docs/es-de/README.md) 和 [iiSU](https://github.com/lidor30/pokedaisy/blob/main/docs/iisu/README.md) 有逐步指南。Cocoon 只列出自己列表中的模拟器，因此需要等 Cocoon 添加后 PokeDaisy 才会出现。
