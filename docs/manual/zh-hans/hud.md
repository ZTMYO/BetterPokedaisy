现代宝可梦游戏在探索时会把队伍、位置和携带物品等重要信息留在屏幕上。HUD 为经典游戏提供类似功能。在单屏设备上，助手通常需要手动展开，因此 HUD 尤其有用；双屏设备也可以使用。

HUD 默认开启。可在任一屏幕设置的 `屏幕` 分组中，通过 `HUD` 关闭或调整外观。

Game Boy 的 Yellow 英文版和 Crystal 也会显示 HUD，无论是否开启 `扩展画面`。这些游戏没有道具图片，因此球以普通球图案和数量显示，背包则像游戏自己一样按名称列出物品。

## 显示的内容

| 部分 | 显示什么 | 点击后的操作 |
| --- | --- | --- |
| 队伍 | 每只宝可梦的图标、等级和生命值条。中毒、睡眠等状态显示在图标上；濒死成员会变淡并显示濒死标记。 | 打开该宝可梦的详情，与 `队伍` 标签页相同；上下操作可切换成员。 |
| 小地图 | 显示周围地区地图、当前位置的头像及下方地点名称。 | 打开完整地图，可使用 `地点` 和 `飞翔`，并保持地图自身的形状。 |
| 精灵球 | 背包中的球及各自数量。Elite Redux 不记录数量，因此只显示球。 | 打开背包的 `精灵球` 口袋。 |
| 剩余步数 | 使用驱避野生宝可梦的道具后，球旁的窗口显示图标和剩余步数，并随行走倒计时；条形由绿变黄再变红，最后 20 步的数字变为金色，效果结束后窗口消失。支持范围与可使用此类道具的[背包](bag.md)相同。 | 打开背包。 |
| `电脑` | 在当前位置打开游戏自己的电脑，无需走到宝可梦中心即可取出或存放宝可梦。角上的小箭头表示它打开游戏自身界面，而不是 HUD 页面。支持范围与有 `电脑` 按钮的[背包](bag.md)相同。 | |
| 背包 | 紧凑背包：口袋显示为标签，物品以带数量的网格显示。选择物品可阅读说明；助手支持时也可以 `使用`。按钮和背包使用与[背包标签页](bag.md)相同的游戏专属名称。 | |
| `野生` | 显示当前区域在草丛、水面、各类钓竿或碎岩中出现的野生宝可梦、等级和概率。尚未见过的成员显示 `???`，小球标记已经捕获的成员；按钮上的红色数字是尚未捕获的数量。 | |

地图、背包、野生列表或详情打开时，游戏仍会运行。点击面板周围或按 `返回` 可关闭。使用 `玻璃` 和 `白色玻璃` 外观时，这些面板也会半透明显示。

`野生` 需要游戏自身的遭遇表，因此只在 `攻略` 标签页有 `当前位置` 页面时显示。助手不能使用的道具，以及针对单个招式使用的道具，在此没有 `使用` 按钮；请从背包标签页或游戏中使用。

## 何时显示

HUD 仅在场景中行走时显示。首次游玩某个游戏时，走几步后它才会出现；PokeDaisy 会学习并记住该游戏的场景外观。进入战斗、队伍或背包等菜单、游戏自己的城镇地图时 HUD 会淡出，之后再次显示。开启 `扩展画面` 时，对话或告示牌出现也会让 HUD 暂时移开。手机竖屏时目前不显示，因为助手位于游戏画面正下方。

未开启 `扩展画面` 时，HUD 显示在游戏画面上，而不是旁边的黑边；专为黑边设计的 `轨道` 布局除外。如果触摸控制显示在游戏上，HUD 会向内移动角落，避免覆盖按钮。

当游戏画面旁没有足够宽度同时容纳队伍和按钮时，例如助手侧栏锁定在游戏旁边，HUD 会缩小：队伍和小地图暂时隐藏，球和按钮位于左下角，`野生` 之后增加一个 `地图` 按钮。队伍仍可通过助手打开。此时 `布局` 不能更改，并提示屏幕太小。

单屏设备上，HUD 显示时，打开助手的入口会以 `伴侣面板` 按钮加入背包和野生按钮旁，而不是停在屏幕边缘。助手窗口打开时入口仍在这里；HUD 在战斗或菜单中移开时，边缘标签恢复。

## 自定义

点击 `布局`、`外观` 或 `大小` 可切换到下一个选项。HUD 会立即变化，方便在游戏画面上比较。

| 设置 | 选项 | 作用 |
| --- | --- | --- |
| `HUD` | **`开启`**、`关闭` | 控制整个 HUD。 |
| `布局` | **`角落`**、`角落 2`、`轨道`、`停靠栏` | `角落` 将小地图放在右上（游戏会在左上显示新区域名），队伍放在左下，其他内容放在右下。`角落 2` 交换右侧位置：小地图在右下，球和按钮在右上。`轨道` 将内容排成屏幕两侧的两列，放在游戏旁的黑边或 `扩展画面` 的额外地图上，不覆盖游戏原画面。`停靠栏` 将队伍、球和按钮放在底部一条栏中，小地图放在右上。 |
| `外观` | **`玻璃`**、`白色玻璃`、`窗口` | `玻璃` 是深色半透明面板，使用浅色文字；`白色玻璃` 是白色半透明面板，使用深色文字；`窗口` 使用应用其他部分的白色窗口样式。 |
| `大小` | `小`、**`正常`**、`大` | 调整 HUD 大小。 |
| `队伍`、`小地图`、`精灵球`、剩余步数、`电脑`、背包、`野生宝可梦` | **`开启`**、`关闭` | 分别显示或隐藏各部分。 |
