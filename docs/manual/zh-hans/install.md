PokeDaisy 不在 Play 商店上架。你可以从其 GitHub 页面下载 APK 安装，之后应用会检查更新。整个过程只需几分钟。

## 下载并安装 APK

1. 在设备的浏览器中打开[最新发行版](https://github.com/lidor30/pokedaisy/releases/latest)。
2. 在 **Assets** 下点击 `PokeDaisy-<version>.apk` 下载。
3. 从浏览器的下载通知或文件管理器的“下载”文件夹中打开下载的文件。
4. 如果 Android 提示不允许从此来源安装应用，请进入系统设置，为浏览器或文件管理器允许安装，然后返回并点击**安装**。
5. 打开 PokeDaisy。

> [!NOTE]
> PokeDaisy 不附带游戏。你需要使用从自己拥有的卡带中提取的 ROM。

## 初次设置

首次打开 PokeDaisy 且游戏库为空时，会显示欢迎向导。向导有五个简短步骤，角落中显示 `1 / 5` 至 `5 / 5`。每个步骤都可以跳过。右下角按钮在尚未选择内容时显示 `跳过`，选择后显示 `下一步`，最后一步显示 `完成`。点击 `返回` 可回到上一步。

这里选择的内容以后都可以在设置中修改。

### 第 1 步：ROM 文件夹

如果你的游戏存放在文件夹中，例如 `ROMs/gba` 和 `ROMs/nds`，可以在这里指定这些文件夹。点击 `选择文件夹` 并选择一个文件夹，再通过 `添加文件夹` 添加其他文件夹。PokeDaisy 会搜索游戏，并显示找到的数量。点击文件夹旁边的 `移除` 可将其移出列表。

建议只选择存放游戏的文件夹，这样需要搜索的文件更少，速度也更快。

游戏会直接从原文件夹运行，应用不会复制游戏。每次回到游戏库时，应用都会重新检查这些文件夹；以后添加游戏时，把文件放入其中即可。

如果你希望使用游戏库中的 `+` 按钮逐个添加游戏，可以跳过此步骤。[游戏库](library.md)介绍了这两种方法。

![设置向导第一步：选择 ROM 文件夹，以及只选择游戏所在文件夹的提示](shots/setup-roms.png "第 1 步：关联 ROM 文件夹")

### 第 2 步：游戏存档

此步骤决定存档文件的存放位置。可以选择：

- `保存在 POKéDAISY 中`：默认选项，将存档放在应用自己的文件夹中。
- **已有存档的文件夹。** PokeDaisy 会列出找到的包含 `.sav` 或 `.srm` 文件的文件夹及其中的存档数量，包括 ROM 文件夹、其中的 `saves` 子文件夹，以及设备或 SD 卡上的 RetroArch 存档文件夹，例如 `RetroArch/saves/mGBA` 或 `RetroArch/saves/gpSP`。
- `选择其他文件夹…`：选择其他位置。

如果之前在其他模拟器中游玩，可以选择其存档文件夹，继续使用原存档。游戏按 ROM 文件名查找存档：例如 `Pokemon Emerald.gba` 对应 `Pokemon Emerald.sav` 或 `.srm` 文件。共享存档的更多说明见[存档、备份和即时存档](saves.md)。

![设置向导第二步：选择应用文件夹或已有的 RetroArch 存档文件夹](shots/setup-saves.png "第 2 步：选择存档位置")

### 第 3 步：游戏按键

此页面显示设备上的哪些按键对应 GBA 按键。请先检查 A 和 B：部分设备印在按键上的字母顺序可能与你预期的相反。如果映射不对，点击相应 GBA 按键所在的行，然后按下希望使用的设备按键。点击 `取消` 或 `返回` 可保留原来的设置。

![设置向导第三步：GBA 按键和各自绑定的设备按键](shots/setup-buttons.png "第 3 步：检查按键")

![选择 GBA B 后，页面等待按下设备按键，并提供取消按钮](shots/setup-buttons-capture.png "点击一行，然后按下想要绑定的按键")

### 第 4 步：封面图片

游戏库可以显示游戏封面。封面来自两个免费服务，各自需要使用你自己的免费账户获取密钥：

- **RetroAchievements** 封面：点击 `打开RetroAchievements`，从打开的页面复制你的 **Web API key**（位于 RetroAchievements 设置页），然后粘贴到按钮旁的输入框。
- **SteamGridDB** 图标：用于 RetroAchievements 没有封面的游戏。点击 `打开SteamGridDB`，复制 API 密钥并粘贴到对应输入框。

提供一个密钥即可。点击 `保存` 后，PokeDaisy 会获取封面。你也可以暂时跳过，之后在设置的 `封面` 中添加密钥。

![设置向导中的封面图片步骤：RetroAchievements 和 SteamGridDB 的密钥输入框](shots/setup-covers.png "第 4 步：添加封面服务密钥")

### 再次运行设置向导

打开设置（游戏库标题栏中的齿轮），在列表末尾的 `应用` 分组中点击 `运行设置向导`。向导会显示在游戏库上方；在第一步点击 `返回` 可以回到设置。

## 所有文件访问权限

在 Android 11 或更新版本中，选择 ROM 文件夹、存档文件夹或某个游戏的专用存档文件夹时，系统会先要求你为 PokeDaisy 开启**所有文件访问权限**。应用需要通过文件路径打开设备各处的游戏和存档，才能直接运行文件夹中的游戏而不复制文件，并把存档写到其他模拟器也能访问的位置。

Android 会打开系统权限页面：开启权限后返回，向导会从离开的位置继续。

如果不授予权限，PokeDaisy 仍可使用：通过 `+` 导入游戏，并将存档保存在应用自己的文件夹中。

> [!NOTE]
> 只能关联设备存储和 SD 卡上的文件夹，不能关联文件选择器中的云文件夹，例如 Google Drive。

## 完成设置后

接下来几次打开游戏库时，可能会出现一些只显示一次的窗口：

- `新功能：扩展画面` 提议启用扩展画面，在游戏原画面边缘之外继续绘制地图，让整个上屏显示游戏。可选择 `开启` 或 `暂时不要`，以后也能在设置的 `画面比例` 中修改。详见[屏幕、画面比例与着色器](screen.md)。
- `发送崩溃报告？` 会询问是否允许应用在崩溃时发送报告。默认关闭，只有同意后才会启用；以后可在设置的 `崩溃报告` 中修改。

然后选择游戏开始游玩。下一页是[游戏库](library.md)。

## 更新

每次打开游戏库时，PokeDaisy 都会检查新版本。如果有更新，会显示 `有可用更新` 和更新内容：

- `更新`：下载新 APK 并打开 Android 安装程序，然后在系统界面点击**更新**。如果系统要求允许 PokeDaisy 安装应用，请允许后返回。
- `发布页面`：在 GitHub 上打开发行页面。
- `稍后`：推迟到下次打开游戏库时再提示。

更新会保留游戏库、存档、即时存档和设置。

更新后首次打开游戏库时，`更新内容` 会显示该版本的主要变化一次。点击 `发布页面` 查看 GitHub 上的完整说明，点击 `确定` 关闭。

![游戏库中的更新提示，包含更新说明和稍后、发布页面、更新按钮](shots/library-update.png "发现更新")

如果要立即检查更新，打开设置，在 `应用` 分组中点击 `版本`。这里会显示当前版本，点击后会检查是否有新版本。

> [!TIP]
> 如果更新反复下载却无法安装，请检查 PokeDaisy 是否有安装应用的权限：在 Android 设置中打开**应用**、PokeDaisy、**安装未知应用**。更多帮助见[疑难解答](troubleshooting.md)。
