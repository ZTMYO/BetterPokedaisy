PokeDaisy 不在 Play 商店上架。你需要从它的 GitHub 页面以 APK 文件的形式安装，之后应用会自己保持更新。整个过程只需几分钟。

## 下载并安装 APK

1. 在设备上，用浏览器打开[最新发行版](https://github.com/lidor30/pokedaisy/releases/latest)。
2. 在 **Assets** 下点击 `PokeDaisy-<version>.apk` 下载。同一个文件适用于所有设备，包括运行 32 位 Android 的旧平板。
3. 打开下载好的文件（可以从浏览器的下载通知打开，也可以到文件管理器的“下载”文件夹中打开）。
4. 如果 Android 提示不允许从此来源安装应用，请进入对应的设置，为你的浏览器或文件管理器允许安装，然后返回，再点击**安装**。
5. 打开 PokeDaisy。

> [!NOTE]
> PokeDaisy 不附带游戏。你需要使用从自己拥有的卡带中提取的 ROM。

## 初次设置

首次在游戏库为空的情况下打开 PokeDaisy 时，它会显示 `欢迎使用 POKéDAISY`：五个简短步骤，角落里的编号从 `1 / 5` 到 `5 / 5`。每一步都可以跳过。右下角的按钮在你做出选择前显示 `跳过`，之后显示 `下一个`，最后一步显示 `完成`。`返回` 会回到上一步。

这里选的所有内容以后都能在设置中修改，所以不用想太多。

### 第 1 步：你的 ROM 文件夹

如果你的游戏放在文件夹里（比如 `ROMs/gba` 和 `ROMs/nds`），可以在这里让 PokeDaisy 指向它们。点击 `选择文件夹` 选一个文件夹，再为其他文件夹点击 `添加文件夹`。PokeDaisy 会逐个查看（显示 `正在查找游戏…`），然后在 `找到 3 款游戏` 或类似文字下列出找到的内容。文件夹旁边的 `移除` 可以把它重新移出列表。

请只选择游戏所在的文件夹，而不是一个装着所有东西的大文件夹：需要查看的内容更少，速度也更快。

这些文件夹里的游戏会直接在原处运行，不会复制任何文件。每次回到游戏库时，应用都会重新检查这些文件夹里有没有新游戏，所以以后要添加游戏，只需把它放进其中一个文件夹。

如果你更想用游戏库里的 `+` 按钮逐个添加游戏，可以跳过这一步。[游戏库](library.md)介绍了这两种方式。

![设置向导第一步：你的 ROM 文件夹，附有只选择游戏所在文件夹的提示和一个“选择文件夹”按钮](shots/setup-roms.png "第 1 步：关联你的 ROM 文件夹")

### 第 2 步：游戏存档

这一步决定存档文件放在哪里。可选方式有：

- `保存在 POKéDAISY 中`（默认）：存档放在应用自己的文件夹里。
- **一个已经存有存档的文件夹。** PokeDaisy 会列出它找到的所有含 `.sav` 或 `.srm` 文件的文件夹，以及每个文件夹里有多少存档：你的 ROM 文件夹（以及每个文件夹里的 `saves` 文件夹），还有设备上及 SD 卡上的 RetroArch 存档文件夹（例如 `RetroArch/saves/mGBA` 或 `RetroArch/saves/gpSP`）。
- `选择其他文件夹…`，可以挑选任何其他文件夹。

如果你已经在用其他模拟器玩这些游戏，就选它的存档文件夹，继续使用同一批存档。游戏按 ROM 的文件名查找存档，所以 `Pokemon Emerald.gba` 会使用 `Pokemon Emerald.sav`（或 `.srm`）。[存档、备份和即时存档](saves.md)有更多关于共享存档的说明。

![设置向导第二步：游戏存档，提供“保存在 POKéDAISY 中”和一个带存档数量的 RetroArch 存档文件夹](shots/setup-saves.png "第 2 步：选择存档位置")

### 第 3 步：游戏按键

这一页显示设备的哪些按键对应各个 GBA 按键。请先检查 A 和 B：有些设备的印字顺序和你想的正好相反。如果有哪里不对，点击那个 GBA 按键所在的行，然后在页面上直接按下你想用的按键。点击 `取消` 或 `返回` 会保持原样。

![设置向导第三步：游戏按键，列出每个 GBA 按键及其绑定的设备按键](shots/setup-buttons.png "第 3 步：检查按键")

![同一步骤中 GBA B 正在等待按键：它所在的行显示“请按下一个按键…”，下方有“取消”](shots/setup-buttons-capture.png "点击一行，然后按下你想用的按键")

### 第 4 步：封面图片

有了盒装封面，游戏库会好看得多。封面来自两个免费服务，每个都需要用你自己的免费账户获取密钥：

- **RetroAchievements** 封面：点击 `打开 RetroAchievements`，从打开的页面复制你的 **Web API 密钥**（在 RetroAchievements 的设置页上），然后粘贴到按钮旁边的输入框里。
- **SteamGridDB** 图标，用于 RetroAchievements 没有封面图的游戏：点击 `打开 SteamGridDB`，复制你的 API 密钥，粘贴到那个按钮旁边的输入框里。

一个密钥就够了。点击 `保存`，PokeDaisy 就会获取你游戏的封面（显示 `正在获取…`）。现在跳过也可以，之后随时能在设置 > `封面` 中添加密钥。

![设置向导最后一步：封面（可选），有一个 RetroAchievements 密钥输入框和一个 SteamGridDB 密钥输入框](shots/setup-covers.png "第 4 步：添加封面服务密钥")

### 再次运行设置向导

打开设置（游戏库中的 `设置`，在左侧或底部），在底部的 `应用` 分组中点击 `运行设置向导`。设置向导会覆盖在游戏库上方打开；在第一步点击 `返回` 会回到设置。

## 所有文件访问权限

当你选择一个文件夹（ROM 文件夹、存档文件夹或某个游戏自己的存档文件夹）时，Android 11 及更新版本会先要求你允许 PokeDaisy 拥有**所有文件访问权限**。应用需要这项权限，才能按路径打开设备任何位置上的游戏和存档，从而直接运行你文件夹里的游戏而不复制它们，并把存档写到其他模拟器也能看到的位置。

Android 会打开它自己的权限页面：开启后返回即可。设置向导会从你离开的地方继续。

如果不允许，PokeDaisy 仍然能用：用 `+` 导入游戏，并把存档保存在它自己的文件夹里。

> [!NOTE]
> 只有设备自带存储和 SD 卡上的文件夹才能使用。文件选择器里的云文件夹（如 Google Drive 之类）无法关联。

## 完成设置后

接下来几次打开游戏库时，可能会出现几个只显示一次的窗口：

- `新功能：扩展画面` 会提议开启 `扩展画面`，它会把地图绘制到游戏边缘之外，让整个上屏都成为游戏画面。可以选择 `开启` 或 `暂时不要`；无论选哪个，之后都能在设置 > `画面比例` 中找到。参见[屏幕、画面比例与着色器](screen.md)。
- `发送崩溃报告？` 会一次性询问：应用崩溃时是否可以发送报告。除非你同意，否则它保持关闭，之后随时可以在设置 > `崩溃报告` 中修改。

然后挑一款游戏开玩。下一页是[游戏库](library.md)。

## 更新

每次打开游戏库时，PokeDaisy 都会检查有没有新版本。有的话，它会显示 `有可用更新` 以及更新内容：

- `更新`：下载新的 APK 并打开 Android 的安装程序。在那里点击**更新**。如果 Android 要求允许从 PokeDaisy 安装应用，请允许后返回。
- `发布页面`：在 GitHub 上打开该发行版。
- `稍后`：推迟到下次打开游戏库时再提示。

更新会保留所有内容：你的游戏库、存档、即时存档和设置。

更新后第一次打开游戏库时，`更新内容` 会显示该版本的主要变化，只显示一次。`发布页面` 会在 GitHub 上打开完整说明，`确定` 则关闭它。

![游戏库中的“有可用更新”窗口，包含发行说明以及“稍后”“发布页面”“更新”按钮](shots/library-update.png "一条更新提示")

如果想立刻检查，打开设置并点击 `版本`（在 `应用` 分组中）。它会显示你当前的版本，点击它会查找更新的版本。

> [!TIP]
> 如果更新总是下载却装不上，请检查 PokeDaisy 是否被允许安装应用（Android 设置中的**应用**、PokeDaisy、**安装未知应用**）。更多内容见[疑难解答](troubleshooting.md)。
