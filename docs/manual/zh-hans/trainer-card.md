训练家卡标签页无需打开 START 菜单即可显示你的卡片：正面有姓名、ID、金钱、图鉴数量、游玩时间和徽章，背面有游戏保存的记录。卡片会在游玩时更新；游玩时间持续计数，小时和分钟之间的冒号像游戏中一样闪动。

卡片不是重新仿制的外观：它从你的 ROM 图形重建，使用游戏的布局、字体、颜色和训练家图片，像素级对应游戏中的卡片。卡片颜色也像游戏中一样随获得的星数变化。

## 打开训练家卡标签页

训练家卡默认不在标签栏中，可以通过两种方式打开：

- **从更多打开**：点击齿轮左边的 `更多`。未放入标签栏的页面会以应用图标显示，点击 `训练家卡`。
- **放入标签栏**：打开 `设置` > `标签栏`，将 `训练家卡` 设为 `已显示`。齿轮旁最多放五个标签，可能需要先隐藏另一个。

标签栏的更多说明见[助手](companion.md)。

## 翻转卡片

点击卡片即可翻面。卡片会像游戏中的动画一样先折起，再展开到另一面。卡片下方的文字说明下次点击会显示哪一面：正面显示 `点按翻转卡片`，背面显示 `点按查看正面`。

背面显示游戏保存的额外记录，例如首次进入名人堂、联机对战和交换。具体内容与游戏中的卡片一样，取决于游戏。

卡片以屏幕能容纳的最大整数倍尺寸绘制，以保持像素清晰。

## 支持训练家卡的游戏

| 游戏 | 卡片 |
| --- | --- |
| FireRed 和 LeafGreen（英文版） | 游戏自己的卡片 |
| Emerald（英文版） | 游戏自己的卡片 |
| Unbound | 使用 Unbound 紫色配色的 FireRed 卡片和 Unbound 自己的玩家角色，不绘制徽章 |
| Glazed | 使用自己的徽章、图片和字体 |
| Emerald Imperium | Emerald 卡片，使用 Imperium 的字体和文字 |
| Emerald Legacy | Emerald 卡片，包含 Legacy 的第五颗星和获得该星后的黑色卡片 |
| SoulGold | 自己的金色城都卡片。星星来自名人堂、地区图鉴、对战开拓区记录和成就 |
| Lazarus | 自己的橙色卡片和字体。星星遵循其自身规则，卡片颜色则遵循原版规则 |
| Recharged Yellow | FireRed 卡片，使用自己的图片、字体和文字，背面显示你选择的六只宝可梦 |

其他游戏暂时没有训练家卡标签页，包括 Ruby、Sapphire 和原版游戏的其他语言版本。许多改版以自己的方式绘制卡片，尚未完成解析。

> [!NOTE]
> 卡片图形来自你的 ROM，因此首次游玩时，训练家卡标签页可能需要片刻才会出现。每个 ROM 只需这样处理一次。
