上屏比 GBA 画面宽，可以选择如何处理游戏周围的空间：保持 GBA 原始形状、拉伸，或让 PokeDaisy 在空隙中绘制更多场景。还可以添加滤镜和边框，并将应用窗口切换为深色。

本页内容均位于两屏设置的 `屏幕` 分组：可从游戏库打开上屏设置，也可打开伴侣面板的 `设置` 标签。`状态栏`、`着色器`、`遮罩` 和 `轻量伴侣面板` 位于 `显示选项` 页面。在伴侣面板中修改后，游戏画面立即更新。

## 画面比例：游戏如何填满屏幕

`画面比例` 有三个选项：

| 选项 | 效果 |
| --- | --- |
| `原始` | 保持 GBA 的 3:2 画面并尽可能放大，左右留黑边。默认选项。 |
| `拉伸` | 水平拉伸游戏以填满屏幕，没有黑边，但画面会比原来宽。 |
| `扩展画面` | 在 GBA 原画面边缘外绘制更多地图，让游戏填满屏幕，像素保持方形且不拉伸。仅限支持的游戏。 |

在上屏打开 `画面比例` 会看到预览：每个选项都显示为一张小上屏图，有最新即时存档截图时会使用它。点击所需选项。在伴侣面板中则是选择列表，选择后游戏立即改变。

![设置中的画面比例选择器，以小图并排预览原始、拉伸和扩展画面](shots/settings-aspect.png "选择前预览上屏效果")

## 扩展画面：显示更多地图

开启 `扩展画面` 后，黑边变成周围更多道路和场景。游戏旁的区域并非拉伸或凭空生成，而是每帧根据游戏自己的地图、图块和人物重建，因此人物可从边缘走入，水会流动，光照也保持一致。手机竖屏时，额外地图显示在游戏上下方。

需要了解：

- **战斗也会变宽。** 战斗背景延伸到边缘外，宝可梦、训练家和生命值框从画面外滑入。有些改版只绘制屏幕宽度的战斗场景，此时会从边缘镜像延伸。文本后方的深色条带和战斗菜单横跨全屏。
- **天气和洞穴有效。** 雾、火山灰和雨延伸到屏幕边缘；黑暗洞穴在光源周围仍保持黑暗。
- **菜单和标题画面**无法延伸，因此两侧区域会柔和显示游戏边缘的颜色，回到地图时再渐变恢复。
- **支持的游戏：** FireRed、LeafGreen、Emerald、Ruby 和 Sapphire（所有语言与修订版），以及 Unbound、Radical Red、Lazarus、SoulGold、Heart and Soul、Gaia、Odyssey、Amethyst 1.3.0、Glazed、Seaglass、Emerald Imperium、Emerald Legacy、Emerald Rogue、Too Many Types 2、Recharged Yellow、Super Mariomon、Ultra Violet、FireRed Rocket Edition、Ash Gray、Ghost Grey、Elite Redux、Sword and Shield Ultimate Plus、GS Chronicles 和 Celia 的改版。
- **DS 游戏：** Platinum、HeartGold、SoulSilver 和 Black。3D 世界及战斗都可延伸到屏幕外：Black 包括天空、地面等整个战斗场景，其他游戏则延伸战斗背景并将生命值框移向边缘。
- **Game Boy：** Yellow 英文版和 Crystal 也支持。城镇或道路、人物都延伸到小屏外，缩放和环顾操作相同。越过边界前，下一城镇或道路的人物会先出现在延伸区域中。文本框、开始菜单、存档提示和选项画面周围保留地图。战斗及其他菜单不会加宽；两侧区域使用屏幕边缘的纯色（大多数为白色，包括 Yellow 训练家卡；上半部分为黑色的画面旁为黑色）。

设置中 `扩展画面` 标记为 `BETA`：以上游戏都能使用，但仍不完美，偶尔可能在边缘看到游戏本身没有显示的内容。如果遇到，请通过[反馈页面](https://pokedaisy.com/feedback/)告知发生位置。

尚不支持的游戏会以 `原始` 画面显示，伴侣面板的选项列表标记 `暂不支持`。你可以保持开启；遇到支持的游戏时会自动生效。

> [!TIP]
> 首次启动受支持的游戏时，PokeDaisy 可能询问是否开启 `扩展画面`。可以选择开启或暂不启用，之后随时可在 `画面比例` 中修改。

### 缩放与环顾

开启 `扩展画面` 后，`缩放` 快捷键逐级缩小画面，显示更远处。默认为 R3（按下右摇杆）或键盘 `C`，可在 `快捷键` 中改绑（见[控制](controls.md)）。战斗、对话和菜单会自动平滑放大，避免文字过小。每个游戏记住所选缩放；再次打开并回到场景后，视图会平滑恢复。如果希望对话、告示牌和菜单也保持缩放，可在设置中关闭 `自动放大`；战斗以及从战斗打开的队伍和背包仍会放大。

**右摇杆**用于环顾。推动时视图移动；松开后保持原位，直到角色行走，视图才平滑返回。行走时持续推动，镜头会朝该方向前看，并保持角色在画面内。

## DS 分辨率：更清晰的 3D

DS 游戏（Platinum、HeartGold 和 SoulSilver）以 3D 绘制世界；原 DS 分辨率仅 256×192，在大屏上边缘会显得锯齿。`DS 分辨率` 可用更多像素绘制 3D。

| 选项 | 效果 |
| --- | --- |
| `原始` | 保持 DS 原始像素，默认选项。 |
| `2x` 至 `8x` | 由设备图形芯片以对应倍数绘制更清晰的 3D。`4x` 大致达到 1080p 屏幕能显示的清晰度；`6x` 和 `8x` 超过该分辨率，可进一步平滑边缘。 |

文字、菜单及游戏平面绘制的内容保留原始像素，各选项下外观相同。

选择 `2x` 或更高并将 `画面比例` 设为 `扩展画面` 时，屏幕外的世界会与画面一次绘制，清晰度相同，行走时两侧保持平滑。缩放到很远时，3D 清晰度会略微降低以保持速度；此时它在屏幕上本来就很小。

注意：

- **图形芯片负载更高。** 游戏变慢或设备发热时可降低倍数。
- **并非所有设备都支持。** 需要较新的图形芯片（OpenGL ES 3.2，近几年多数掌机支持）。不支持的设备在该行显示 `N/A`，游戏使用 `原始`。
- **部分着色器暂时停用。** `平滑` 和 `无背光屏幕` 处理 DS 原始像素，因此 `2x` 及以上时关闭；`滤镜` 和 `GBA 色彩` 仍然生效。
- 伴侣面板仅在运行 DS 游戏时显示该行，修改后立即生效。

## 状态栏

`状态栏` 添加一条细栏，显示游戏名称、当前位置、金钱、时间和电量。全屏游戏看不到设备时钟时很方便。

| 选项 | 位置 |
| --- | --- |
| `关闭` | 不显示状态栏（默认）。 |
| `游戏` | 横跨游戏顶部，宽度与游戏相同；游戏稍微缩小以腾出空间。 |
| `伴侣面板` | 位于下屏伴侣面板标签上方，游戏保持完整大小。 |

时钟遵循设备的 12 或 24 小时设置。仅在 PokeDaisy 能读取金钱的游戏中显示金钱。

![游戏上方的状态栏显示游戏名、当前城镇、金钱、时间和电量](shots/status-bar.png)

## 着色器

`着色器` 打开游戏画面效果页面。效果可以叠加：可同时使用平滑、GBA 色彩、无背光屏幕和滤镜。

![着色器页面包含滤镜、网格、平滑、GBA 色彩、无背光屏幕和在伴侣面板上等选项](shots/settings-shaders.png)

### 滤镜

每次点击 `滤镜` 都会切换到下一个选项，可以边切换边观察游戏变化（从伴侣面板操作立即生效；从上屏操作则返回游戏后生效）。

| 滤镜 | 外观 |
| --- | --- |
| `无` | 干净的原始像素（默认）。 |
| `LCD` | GBA 的细密像素网格。 |
| `LCD 纸张` | 淡纸纹上的柔和网格，类似无背光掌机屏幕。 |
| `扫描线` | 行之间的暗线，类似老电视。 |
| `CRT` | 柔和发光的光束和彩色掩膜，类似近看的显像管电视。 |

`网格` 控制 `LCD` 和 `LCD 纸张` 的网格强度：`柔和`、`中等`（默认）或 `强`。其他滤镜下该选项变灰。

### 平滑

`平滑` 在滤镜绘制前圆滑像素画的方块边缘，适合喜欢比锐利像素更干净、绘画感更强的外观。点击依次切换：

- `关闭`：原始像素（默认）。
- `xBRZ`：锐利、边缘最干净。
- `xBR`：更圆润柔和。
- `SCALEFX`：轮廓最均匀。

平滑只应用于游戏，不应用于伴侣面板。设备图形芯片无法运行时，该行显示 `N/A`。

### GBA 色彩

GBA 原屏幕比现代屏幕更暗、饱和度更低，游戏色彩也针对它选择。`GBA 色彩` 还原当时的外观，可与任何滤镜配合，默认关闭。

### 无背光屏幕

初代 GBA 屏幕后没有灯光。环境光穿过屏幕并从暗灰绿色背板反射，画面白色区域因此显示背板而非发光，深色像素还会在背板右下方投下淡淡阴影。`无背光屏幕` 模拟这一效果，比亮白色更柔和，可与 `GBA 色彩` 和 `LCD` 滤镜搭配，默认关闭。

### 同时应用到伴侣面板

`在伴侣面板上`（默认开启）将相同的 `滤镜` 和 `GBA 色彩` 应用于伴侣面板及状态栏，使双屏外观一致；不应用 `无背光屏幕`。网格按游戏像素大小设置，与上屏线条对齐。此功能需要 Android 13 或更新版本；旧设备的伴侣面板保持原样。

## 遮罩：游戏周围的边框

`遮罩` 在游戏周围绘制边框，填充 3:2 画面留下的空间。PokeDaisy 内置两种：

- `DAISY`：PokeDaisy 蓝色背景、点阵及边缘花朵标志。
- `边框`：简单的深色边框。

它们按游戏自身像素大小绘制，游戏在内部以整数倍缩放，因此画面保持清晰（有边框时游戏会略小）。

![DAISY 边框中的游戏：蓝色点阵边框和屏幕旁的 PokeDaisy 花朵](shots/overlay-daisy.png)

### 自己的 RetroArch 遮罩

如果已经在 RetroArch 使用遮罩，可以导入。在上屏打开设置 > `遮罩`，点击 `导入文件`。可以选择：

- RetroArch 遮罩 `.cfg` 及其 PNG 图片；
- 包含遮罩的 `.zip`；
- 或屏幕位置有透明孔的任意 PNG。

PokeDaisy 从 `.cfg` 或 PNG 透明部分确定游戏位置。没有透明孔的 PNG 会用作游戏背景。如果 `.cfg` 没有附带图片，应用会要求 `选择图片`。同时包含横屏和竖屏版本的包会选用适合屏幕的版本。

导入的遮罩列在 `已导入` 下。点击使用，或选择 `移除` 删除。导入后也可从伴侣面板的 `遮罩` 列表选择。

![遮罩页面：内置的无、DAISY 和边框选项，已导入列表及导入文件按钮](shots/settings-overlay.png)

> [!NOTE]
> PokeDaisy 不附带或链接任何第三方遮罩。多数主机边框带有厂商标志，请使用你已有的遮罩。

手机竖屏时游戏横跨顶部，遮罩会关闭。使用 `拉伸` 时，游戏会填满遮罩的屏幕区域。

## 深色模式

`深色模式` 同时将双屏应用的白灰色窗口改为深石板色和浅色文字，适合夜间或昏暗环境。每次点击该行切换到下一个选项，可立即查看：

- `关闭`：浅色窗口（默认）。
- `开启`：始终使用深色。
- `自动`：跟随设备深色主题设置。

游戏本身的美术保持原样：队伍格位、地图、训练家卡和战斗按钮仍使用游戏颜色，其背后的背景变暗。

## 主题

`主题` 选择上屏游戏库、设置和初次设置背后的背景。`POKéDAISY`（默认）采用网站的浅色页面，带柔和色块和漂浮标志。其他是游戏配色主题：`FIRERED`、`LEAFGREEN`、`EMERALD`、`RUBY`、`SAPPHIRE`、`PLATINUM`、`HEARTGOLD` 和 `SOULSILVER`。

主题只改变游戏外的上屏。游玩时，伴侣面板始终使用当前游戏自己的外观。

![设置中的主题选择列表，选中 POKéDAISY，下方列出游戏主题](shots/settings-theme.png)

## 帧率 / CPU

`帧率 / CPU` 在游戏左上角显示小型读数：过去一秒游戏运行的帧数及 PokeDaisy 的 CPU 使用量。正常速度应约为 60。

点击读数可打开详细面板，查看帧时间、延迟帧、屏幕刷新和帧节奏、音频供给不足、电池温度、温度状态及内存。游戏卡顿时很有用；参见[故障排查](troubleshooting.md#the-game-feels-choppy-or-the-device-runs-hot)。

## 低性能设备的轻量伴侣面板

较慢的掌机上，伴侣面板可能使设备过于繁忙，导致按键延迟到达游戏：按键后短暂没有反应，常发生在选择 `战斗` 后面板绘制招式时。`轻量伴侣面板` 可减轻负担：

- 仅在显示内容变化时重绘，最多每秒两次（战斗菜单变化仍立即显示）；
- 关闭队伍图标跳动、地图光标闪烁、标签滑动和战斗按钮淡入淡出等动画；
- 关闭 `着色器` 下的 `在伴侣面板上`，不在面板上绘制滤镜。

默认的 `自动` 会在设备性能看起来较低时自行开启，也会在任何设备多次出现按键延迟后开启，并记住该决定。设置下方的文字说明 `自动` 的决定；也可自行选择 `开启` 或 `关闭`。

## 其他屏幕设置

- `交换屏幕`（双屏设备）将游戏放在第二屏，伴侣面板放在主屏，适合下屏为主屏的设备。参见[屏幕与设备](devices.md)。
- `伴侣面板`（单屏设备竖屏）可选择 `位于底部` 或 `游戏下方`。参见[屏幕与设备](devices.md)。
