PokeDaisy 在 AYN Thor 等掌机上开箱即用：面键、肩键、START 和 SELECT 对应 GBA 按键，一些组合键执行即时存档等模拟器操作。本页说明如何修改按键和快捷键，以及连接手柄或使用触屏时的行为。

两屏设置的 `控制` 分组都有按键设置：游戏库打开的上屏设置和伴侣面板的 `设置`。`自动跑步`、`室内跑步`、`野生遭遇` 和 `异色概率` 改变游戏本身，因此位于伴侣面板靠前的游戏玩法分组。

## 游戏按键

`游戏按键` 设置每个 GBA 按键对应的实体按键。页面按按钮逐行显示当前绑定，分为所有游戏、DS 游戏专用、GBA 和 Game Boy 游戏专用三组。

| 分组 | 按钮 | 默认 |
| --- | --- | --- |
| `所有游戏` | `GBA A` 和 `GBA B` | A 和 B |
| | `GBA L` 和 `GBA R` | L1 和 R1 |
| | `GBA START` 和 `GBA SELECT` | START 和 SELECT |
| | GBA A 连发和 B 连发 | 无 |
| `DS 游戏` | `X` 和 `Y` | X 和 Y |
| `GBA 和 GAME BOY` | `START 2` 和 `SELECT 2` | X 和 Y |
| | `发送至伴侣` | X |

`X` 和 `Y` 是 DS 游戏自己的 X 和 Y。GBA 和 Game Boy 没有 X、Y，因此为这些游戏单独提供 `START 2` 和 `SELECT 2` 作为第二组 START、SELECT，让 X 打开菜单、Y 使用登记道具，类似 DS 游戏。双屏掌机上，`发送至伴侣` 在场景中还有一个功能，见[按 X 将按键转交给伴侣面板](#x-takes-your-buttons-to-the-companion)。每个 GBA 按键也有键盘键位（Z、X、A、S、Enter 等），供键盘使用。

DS 与 GBA 游戏不会同时运行，因此一个实体按键可同时属于两组：X 可同时是 DS 的 `X` 和其他游戏的 `START 2`。修改一组不会改变另一组。可以让 GBA 游戏中的 X 留给伴侣面板，同时把 `START 2` 绑定到其他按键；也可以清除 `发送至伴侣`，让 X 只作为第二个 START。

游戏运行时，伴侣面板的 `游戏按键` 在 `所有游戏` 下显示当前游戏对应的分组；上屏设置显示三组。

修改时点击对应行，出现 `请按下一个按键…` 后按设备上的目标键。两屏操作相同；在伴侣面板中等待输入时，游戏屏幕会显示窗口，提示按键并显示正在按住的键。`取消` 或 `BACK` 保留原绑定。A、B 连发以及 GBA 和 Game Boy 分组还提供 `清除`，可移除该行的所有绑定。

新按键替换该行全部绑定，包括键盘键位。一个按键在同一游戏中只能执行一个功能：绑定到新行时会离开同一游戏组中的旧行。`发送至伴侣` 是例外，可与其他功能共用按键。

> [!NOTE]
> 按键名称遵循 Android 使用的 Xbox 手柄布局。AYN 和 Retroid 设备上，即使印字不同，`A` 也指最下方的面键。如果觉得 A、B 反了，可在此交换。

方向键和模拟摇杆始终负责移动，不能重新映射。初次设置也列出这些按键，并可用相同方式修改。

![上屏的游戏按键页面，按所有游戏、DS 游戏及 GBA 和 Game Boy 分组列出绑定](shots/settings-buttons.png "上屏的游戏按键")

## 按 X 将按键转交给伴侣面板

在双屏掌机的 GBA 或 Game Boy 游戏中行走时，按 `X`（`游戏按键` 中的 `发送至伴侣`），按键会转交下屏伴侣面板，类似 DS 游戏的触屏菜单。游戏底部会滑出带向下箭头的银色条，伴侣面板标签栏两端出现 `L` 和 `R`。

按键转交期间，游戏继续运行但不会收到按键：

- 方向键移动光标，`A` 选择当前项目。
- `L` 和 `R` 切换标签。
- `B` 返回；没有更多内容可返回时，将按键交回游戏。
- `X` 或 `START` 可从任何位置交回按键；点击银色条也可以。

游戏需要按键时也会自动收回，例如战斗开始，或从伴侣面板打开电脑、飞翔等游戏操作。

`X` 仅在场景中没有其他操作时转交按键。在文本框、菜单和战斗中，只要 X 也绑定到 `START 2`，它仍作为 `START`。DS 游戏保留自己的 X。

## A 和 B 连发

按住 `A 连发` 或 `B 连发` 时会反复按对应按键，适合快速翻过文字或其他需要连续按键的场景。默认没有绑定，需在 `游戏按键` 中设置。

连发按游戏时间计算，因此快进时也会加快。伴侣面板的对战按钮代替你操作游戏时，连发会暂停。

## 快捷键

快捷键执行游戏之外的操作，如即时存档、快进和退出。快捷键可以是单个按键，也可以是多个按键同时按住的**组合键**。例如按住 SELECT 再按 R1，第二个键触发 SELECT + R1。

组合键不会单独占用游戏按键：单按 SELECT 仍传给游戏，只有同时按 SELECT + R1 才保存即时存档。

当 SELECT 或 START 是组合键一部分时，松开才会传给游戏，避免按住 SELECT 准备 SELECT + START 时提前在游戏中触发。如果按住 SELECT 或 START 时再按其他游戏键，或之前已按住其他键，它会立即传给游戏，保持游戏自己的组合键可用。

下列未注明手柄或键盘的操作，在该设备上没有默认绑定。`重新启动游戏`、`关闭应用` 和 `伴侣面板` 均需自行绑定。

- **保存即时存档：** 保存到当前槽位。手柄 SELECT + R1；键盘 F1。
- **读取即时存档：** 读取当前槽位。手柄 SELECT + L1；键盘 F2。
- **撤销保存：** 恢复上次保存覆盖的即时存档。键盘 F3。
- **撤销读取：** 返回上次读取前的位置。键盘 F4。
- **下一个槽位：** 切换到下一个即时存档槽位。键盘 `]`。
- **上一个槽位：** 切换到上一个即时存档槽位。键盘 `[`。
- **按住快进：** 按住期间快进。手柄 R2；键盘空格。
- **切换快进：** 开启或关闭快进。键盘 Tab。
- **切换速度：** 在 1x、1.5x、2x、3x、4x 间切换。手柄 L2；键盘 `=`。
- **按住慢动作：** 按住期间半速。键盘减号。
- **按住倒退：** 倒放最近时刻，需开启倒带。键盘 R。
- **缩放：** 逐级缩放，画面比例需设为扩展画面。手柄 R3（显示为 `THUMBR`）；键盘 C。
- **软重启：** 执行游戏自己的 A + B + SELECT + START 重启，回到标题画面；上次游戏内存档后的内容会丢失。键盘 H。
- **退出游戏：** 返回游戏库。手柄 SELECT + START；键盘 Esc。
- **重新启动游戏：** 从存档重新启动，与伴侣面板设置中的重启相同。
- **关闭应用：** 退出游戏（照常保存）并完全关闭 PokeDaisy，使其从最近应用中消失。
- **快捷菜单：** 打开或关闭[快捷菜单](#the-quick-menu)。手柄 L3（显示为 `THUMBL`）。
- **伴侣面板：** 单屏时在游戏上打开面板，也可在关闭伴侣面板后恢复；边缘按钮可通过 `伴侣面板按钮` 隐藏。

`重新启动游戏`、`关闭应用` 和 `伴侣面板` 默认没有绑定。速度快捷键见[快进与游戏速度](fast-forward.md)，即时存档和倒带见[存档](saves.md)，缩放见[屏幕](screen.md)。

![上屏快捷键页面：快捷键总开关及各快捷键的绑定](shots/settings-hotkeys.png "上屏快捷键")

### 更改快捷键

在上屏设置 > `快捷键` 或伴侣面板设置 > `快捷键` 中点击某项，出现按键提示后按一个键，或同时按住多个键再松开。等待输入时：

- `清除` 使其没有绑定，显示 `-`。
- `取消` 或 `BACK` 保留原绑定。

从伴侣面板操作时，游戏屏幕会显示等待窗口及正在按住的键，因为按键发往该屏。期间游戏和其他快捷键都不会收到这些输入。

![伴侣面板等待快捷键时的游戏屏幕，显示保存即时存档、已按按键、清除和取消](shots/game-capture.png "等待输入时的游戏屏幕")

新按键替换该快捷键的全部绑定，包括键盘键位。

![伴侣面板快捷键页面及各项绑定](shots/companion-settings-hotkeys.png "伴侣面板快捷键")

![伴侣面板等待读取即时存档快捷键输入，显示已按的 SELECT + R1、清除和取消](shots/companion-settings-hotkeys-capture.png "等待快捷键输入")

### 按键已被占用

如果选择的按键与另一个快捷键完全相同（顺序不限），会出现 `按键已被使用`。点击 `更改` 从另一个快捷键移走绑定，或取消以保持两者原样。只共享部分按键没有问题：SELECT + R1 与 SELECT + L1 可以共存，这正是组合键的工作方式。

### 关闭快捷键

页面顶部的 `快捷键` 开关可一次关闭所有快捷键。绑定会保留但变灰，所有按键直接传给游戏。如果游戏需要的组合与快捷键冲突，而你不想重新绑定，此功能很有用。

## 快捷菜单

快捷菜单把原本需要翻找菜单的操作集中到一个按钮。按 L3（按下左摇杆）后，操作以圆环或网格显示在游戏上方（见下文 `样式`）。其他 HUD 内容淡出，已打开的详情、地图、背包或野生列表面板会关闭。

| 操作 | 功能 |
| --- | --- |
| `PC` | 在当前位置打开游戏自己的电脑，见[背包](bag.md)。 |
| `飞翔` | 列出可飞往的地点，选择后出发；队伍需要有会该招式的宝可梦。 |
| 驱虫喷雾 | 使用背包中驱赶野生宝可梦的道具，方块显示图标和名称。有多种时会列出数量和各自持续步数供选择。喷雾仍生效时变灰并显示剩余步数。 |
| 自行车 | 骑上自行车；骑行时显示下车并可下车。 |
| 钓竿 | 使用最好的钓竿，请先面向水面。 |
| 野生 | 关闭 `野生遭遇`，再次选择可开启；角落关闭标记表示已关闭。仅在支持该功能的游戏中显示。 |
| 保存／读取即时存档 | 保存或读取当前槽位。 |
| 快进 | 开启或关闭快进。 |
| 伴侣面板 | 单屏设备上打开伴侣面板。 |

按 L3 后菜单保持打开：用方向键或左摇杆移动（圆环中将摇杆指向操作），按 `A` 使用，`B` 或再次按 L3 关闭，也可点击屏幕上的操作。菜单打开时按键操作菜单，游戏在下方继续运行。

暂不可用的操作变灰并说明原因，例如正在战斗或背包没有所需物品。自行车和钓竿使用游戏自己的登记道具方式，剩余行为由游戏决定；不能骑行或钓鱼时游戏会提示。它们支持 FireRed、LeafGreen、Ruby、Sapphire、Emerald，以及基于这些游戏的 Emerald Kaizo 和 Ultra Violet，还支持 SoulGold 自己的 `SELECT` 轮盘（暂借底部槽位，用后恢复原设置）。电脑、飞翔和喷雾只在[背包](bag.md)及[地图](map.md)提供这些功能的游戏中显示。

在任一屏幕设置的 `控制` > `快捷菜单` 中可选择显示哪些操作并关闭其他项。`样式` 点击切换：

- `圆环`（默认）：操作等距排列成圆圈，类似现代游戏的武器轮盘。左摇杆指向某项时名称显示在中央，切换项目有轻微振动；方向键也可逐项移动。
- `网格`：等大的方块按行排列，方向键逐项移动。

`标签` 默认开启，在图标下显示名称。关闭后只显示更小、更紧凑的图标；选中项名称显示在行下方或圆环中央。要改用其他按键，修改 `快捷菜单` 快捷键。

## 触屏按键

`触屏按键` 在游戏上叠加虚拟按键，适合没有实体按键的手机或未连接手柄的平板。两屏设置的 `控制` 分组都有独立页面。顶部预览显示当前按键并随设置立即更新；竖屏时只显示按键周围区域以便放大。预览下方按钮显示手机方向（竖屏或横屏），点击切换预览。点击页面选项可切换到下一个值。

![手机竖屏的触屏按键页面，上方是屏幕和按键预览，下方是设置](shots/settings-touch-phone.png "手机触屏按键")

- **显示**：`自动`（默认）仅在没有连接手柄时显示，按下实体键后立即隐藏；`始终` 始终显示，`从不` 不显示。手机没有连接设备时自动显示。
- **布局**：`两侧`（默认）将按键放在横屏游戏两侧黑边，不遮画面；黑边过窄（如旧款 16:9 手机或竖屏）时按 `经典` 布局。`经典` 将方向键放左下、A/B 放右下、START/SELECT 放中间、L/R 放上角。`紧凑` 更小、更靠近角落，SELECT 在方向键上方、START 在 A/B 上方。`自定义` 是在 `编辑布局` 中制作的布局，制作后出现；选择预设不会删除它。
- **编辑布局**：自行移动按键，见下文。

DS 游戏还会按 DS 的布局在 A/B 周围显示 X 和 Y：X 在上，Y 在左。

- **位置**：手机竖屏时选择按键在可用区域的顶部、中部（默认）或底部。区域是游戏与面板之间的空隙，无空隙时为游戏画面。`自定义` 布局保持自己的位置。`扩展画面` 加 `游戏下方` 时按键拥有恰好适合的空间，该设置变灰。
- **伴侣面板**：手机竖屏时选择 `游戏下方`（默认，屏幕底部留给按键）或 `位于底部`。与 `显示选项` 中同名设置相同，仅在手机等单屏设备显示。开启 `扩展画面` 时，游戏填满面板上方，因此 `游戏下方` 会在面板下方屏幕底部给按键独立区域，绝不遮挡游戏；没有触屏按键时该选项变灰。
- **大小**：同时将所有按键设为小、正常、大或特大。
- **不透明度**：25% 至 100%，默认 50%。
- **方向键**：八方向（默认）支持斜向；四方向一次只按一个方向，适合菜单中经常误走斜向时使用。
- **闲置时淡出**：停止触摸数秒后淡为浅轮廓，下次触摸恢复。
- **振动**：每次按键轻振，默认关闭，遵循手机自身触摸振动设置。
- **重置布局**：清除自定义布局并恢复预设；只在制作自定义布局后显示。

手机竖屏时，空间足够则按键位于游戏与面板之间，见[屏幕与设备](devices.md)。手指无需抬起即可从一个键滑到另一个，例如方向键之间或 B 滑到 A；触摸 A、B 之间会同时按下两键。

### 额外按键

`额外按键` 分组可逐个启用或关闭 GBA 原本没有的按键：

- **快进**（默认开启）：点击切换快进，按住则仅在按住时快进；快进开启时文字亮起。
- **快捷菜单**（默认开启）：打开[快捷菜单](#the-quick-menu)，手机本来没有该实体键。点击方块执行，点击其他位置关闭。
- **A 连发**和 **B 连发**：按住时反复按对应键，与[连发按键](#turbo-a-and-b)相同。
- **保存即时存档**和 **读取即时存档**：保存或读取当前槽位，与快捷键相同。误读后可用 `撤销读取` 快捷键返回。

### 移动和调整按键：编辑布局

`编辑布局` 以实际大小和虚线轮廓显示所有按键。从伴侣面板设置打开时覆盖实际游戏；从上屏设置打开时覆盖游戏画面的图片。

![手机横屏编辑布局：按键位于游戏两侧，顶部栏包含完成、启用对齐和重置](shots/settings-touch-edit.png "编辑布局")

- **移动按键：** 拖动。
- **调整大小：** 双指缩放，或点击后使用顶部栏的 `-` 和 `+`。每个按键可在通常大小的半倍至两倍之间调整，并叠加 `大小` 设置。
- **隐藏按键：** 点击后选择 `隐藏`；通过隐藏项恢复。
- **启用对齐**将按键对齐小网格；点击切换为 `关闭对齐` 可自由放置。
- **重置**将所有按键放回预设位置。
- **完成**或 `BACK` 保存布局，`布局` 变为 `自定义`。

手机竖屏和横屏各有独立布局，编辑当前方向；旋转设备可编辑另一方向。换手机或开启状态栏后布局仍能保持：每个按键保留与最近边缘的距离。

## 跑步：自动跑步与室内跑步

`自动跑步` 在游戏允许跑步后自动运行：场景行走无需按住 B，按住 B 反而步行。按住 A 也会步行，因此 Seaglass 等游戏中按住 A 潜行的 DexNav 功能仍可使用。其他地方 B 保持原样，包括菜单、战斗、对话和自行车骑行（B 在骑行中另有功能）。首次游玩时，行走数秒后生效。Heart and Soul、SoulGold、Too Many Types 2、Emerald Rogue 和 Quetzal 中目前不总能判断是否骑车。Elite Redux 自带 R 键自动跑步，请使用其中一种，不要同时使用。

`室内跑步` 允许在原本只能步行的建筑内跑步，支持基于 FireRed 或 Emerald 的游戏。Ruby 和 Sapphire 显示 `N/A`：这些游戏决定可跑位置的方式无法安全修改。

尚无法读取场景的游戏中，两项都显示 `N/A`。

## 野生遭遇

伴侣面板游戏玩法分组的 `野生遭遇` 控制草丛、洞穴和水中的野生宝可梦是否出现：

- `开启`（默认）保留游戏原有概率。
- `关闭` 完全关闭随机遭遇。

只有随机遭遇改变。钓鱼、吸引野生宝可梦的招式及剧情安排的战斗仍会发生，驱虫道具也照常生效。修改立即应用，无需重启。

支持所有语言的 GBA 原版及几乎所有受支持改版，包括使用较新源码重建的 SoulGold、Lazarus 和 Recharged Yellow。Game Boy 上支持 Red、Blue、Yellow（所有语言）、PureRed、PureBlue 和 Crystal。Emerald Rogue、Quetzal 和其他 Game Boy 游戏显示 `N/A`。

## 异色概率

伴侣面板游戏玩法分组的 `异色概率` 设置野生宝可梦出现异色的概率：

- `正常`（默认）保留游戏原概率；原版为 1/8192。
- `1/4096`、`1/1024`、`1/512` 和 `1/128` 逐渐提高概率。

适用于草丛、洞穴、水中、钓竿遇到的所有野生宝可梦及剧情安排的特殊宝可梦；训练家宝可梦、赠送、蛋和交换不变。修改从下一次遭遇生效，无需重启。

恢复 `正常` 后，已捕获的异色仍为异色，之前捕获的宝可梦也不会被修改。通过此方式生成的异色保留性格、性别、特性、个体值和招式。但其隐藏值之间与游戏自然异色不同的关联可能被存档检查器识别，因此转移到较新游戏时可能被标记。

提高概率期间，[成就](achievements.md)会暂停，因为某些成就集奖励捕获异色。

支持所有语言和修订版的 FireRed、LeafGreen、Ruby、Sapphire、Emerald 原版，以及 Unbound（包括法语版）、Radical Red、Gaia、Odyssey、Amethyst、Sword and Shield Ultimate Plus、GS Chronicles、Emerald Kaizo、Emerald Legacy、Recharged Emerald（包括 Rebalanced）、Glazed、Ultra Violet、Orange Islands、FireRed Rocket Edition、Ash Gray、Recharged Yellow、Lazarus、Emerald Seaglass、Too Many Types 2、Emerald Imperium、Super Mariomon、SoulGold、Team Rocket Edition、Elite Redux 和 R.O.W.E.。许多改版本身已有更高概率：Unbound、Glazed、较新版 Amethyst 和大多数以较新源码重建的改版为 1/4096，Emerald Imperium 约 1/1800，SoulGold 为 1/256，Odyssey 约 1/257。`正常` 保留这些概率，选择未提高概率的值不会产生变化。其他游戏（包括 Game Boy 和 DS）显示 `N/A`。

## 外接手柄

支持蓝牙和 USB 手柄（8BitDo、GameSir、Xbox 等），游戏运行中可连接，无需重启。连接或断开时游戏屏幕会短暂提示。手柄按键与内置按键一样遵循 `游戏按键` 和 `快捷键`，方向键斜向会同时按下两个方向。

手柄 HOME 或向导键未绑定其他功能时，相当于点击 `BACK`（见下文）。

> [!NOTE]
> 外接手柄尚未广泛测试。如果行为异常，请报告手柄名称。

## 模拟 L2 和 R2

部分掌机和手柄（例如 Retroid）将 L2、R2 扳机作为模拟值发送，而非按键。PokeDaisy 将扳机按过一半视为按下 L2 或 R2，因此它们像其他按键一样遵循设置：默认 R2 为 `按住快进`，L2 为 `切换速度`；关闭 `快捷键` 后不再触发，可绑定到任何功能，包括 GBA 按键。快捷键优先处理，随后才传给游戏。

## BACK 按钮

`BACK` 根据按压时长执行两种功能：

- **点击**作为伴侣面板返回，关闭选择列表、宝可梦详情或设置子页面等，并逐级返回。没有内容可关闭时无操作，因此不会意外退出游戏。如果通过 `关闭伴侣面板` 关闭过面板，点击可恢复。
- **长按**退出游戏，返回游戏库或启动游戏的前端。

两屏均适用。单屏设备上，点击还会滑入或收起伴侣面板，见[屏幕与设备](devices.md)。
