游戏运行时，下屏上的内容统称为伴侣面板。它会在游玩过程中读取游戏，因此无需打开上屏菜单也能随时查看最新的队伍、背包、位置和战斗。面板采用游戏自己的菜单风格：FireRed 使用 FireRed 的队伍界面，Emerald 使用 Emerald 的风格，受支持的改版如有自己的风格也会使用。

无需单独启动面板。打开受支持的游戏，加载完成后面板会自动填充。单屏设备则在游戏旁的面板中显示（见[屏幕与设备](devices.md)）。

## 标签页

伴侣面板底部是一排标签，右端有 `更多`（九宫格）和设置齿轮。默认显示：

| 标签 | 内容 |
| --- | --- |
| `队伍` | 队伍及每只宝可梦的完整详情。参见[队伍与详细信息](party.md)。 |
| `图鉴` | 带已见和已捕获标记的图鉴。参见[图鉴](dex.md)。 |
| `地图` | 显示当前位置的地区地图。参见[地图](map.md)。 |
| `背包` | 背包的所有口袋。参见[背包](bag.md)。 |
| `攻略` | 提示、下一位首领和周围信息。参见[攻略](guide.md)。 |

其他几个标签起初不在栏上，位于 `更多` 中：`训练家卡`、`即时存档` 和 `成就`（[RetroAchievements](achievements.md)）。为游戏开启 [Nuzlocke](nuzlocke.md) 追踪后，`NUZLOCKE 挑战` 也会加入。

有些标签只在游戏具备所需数据时显示：`图鉴` 需要游戏的图鉴数据，`攻略` 需要该游戏的攻略，因此缺少这些数据的游戏标签较少。背包标签也使用各游戏的名称：Gold、Silver、Crystal、Crystal Clear 和 Prism 为背包，Unbound 为立方包，R.O.W.E. 为物品栏，Super Mariomon 为口袋，其他游戏为背包。

### 进入游戏之前

游戏仍在标题、开场或 CONTINUE 菜单时，`队伍`、`背包`、`地图` 和 `训练家卡` 会等待：显示游戏自己的空队伍格位和闪动的开始提示，不显示游戏此时可能已加载的队伍。一旦进入行走或战斗就会填充。从上次位置恢复的游戏已处于游戏中，因此立即显示。`即时存档`、`设置` 等始终可用，标题画面也能读取即时存档。

### 选择标签

齿轮旁最多放五个标签。打开设置，在伴侣面板分组点击 `标签栏`，或点击 `更多` 底部的 `标签栏` 按钮。每个标签显示 `已显示` 或 `已隐藏`，点击切换。标题显示已放置数量（如 `5/5`）。栏满时请先隐藏一个。无论选择哪些，标签在栏上的顺序固定。当前游戏没有某个已选标签（如没有图鉴）时，其位置由游戏的其他标签补上，只要游戏标签足够就会保持满栏。

选择由所有游戏共享。当前游戏没有的标签显示 `N/A`，其设置仍为支持该标签的游戏保留。

![伴侣面板设置中的标签栏页面，列出每个标签的显示或隐藏状态](shots/companion-settings-tabs.png "设置 > 标签栏")

### 不在栏上的标签

隐藏的标签仍可一键打开。点击齿轮左侧的 `更多`，所有未放在栏上的标签会以彩色图标和名称显示。点击即可打开；打开期间 `更多` 保持高亮，BACK 返回该页面。

图标下方的提示说明可自行选择栏上的标签，`标签栏` 按钮直接打开设置中的对应页面。如果游戏的所有标签都已在栏上，`更多` 不显示。

![更多页面以应用图标显示即时存档和成就，下方是标签栏按钮](shots/companion-more.png "更多")

### 对战标签

战斗开始时，`对战` 标签出现在栏首并自动打开。为腾出空间，已选标签中最后一个暂时移开；战斗结束后恢复原来打开的标签。详见[对战](battle.md)。

如果希望战斗开始时留在当前页面，可在下文的 `调整` 中关闭 `自动切换至对战`：标签仍会出现，但不自动打开。

## BACK 按钮

设备的 BACK 按钮可从任一屏幕操作伴侣面板：

- **点击 BACK** 返回面板中的上一步：关闭详情、选择列表、弹窗或设置子页面，或从 `更多` 打开的标签返回。
- **长按 BACK** 退出游戏。

手柄的 HOME 或向导按钮在未绑定其他功能时，相当于点击 BACK。

## 按钮声音

伴侣面板按钮播放从 ROM 自身录制的游戏菜单点击声，因此听起来与游戏一致。代替你按游戏按键的按钮（例如对战按钮）保持静音，因为游戏会自行发声。没有振动。要关闭点击声，可在设置中关闭 `点击音效`。

## 设置标签

齿轮打开伴侣面板的设置，布局类似 FireRed 的 OPTION 画面。标题显示游戏名称和电量。点击一行可更改：开关行直接切换，多选行打开简短选择列表，右端带箭头的行打开独立页面。设置会记住位置，切换标签后返回仍在同一行。

![伴侣面板设置标签，顶部为快进与速度分组](shots/companion-settings.png "伴侣面板设置")

选项按组排列，游玩时常用的在前：

- **换装**：`主角外观`、`对手外观`、`文本样式`、`跟随宝可梦` 和 `昼夜变化`，为游戏带来新外观。它位于顶部蓝框中，仅在某项功能适用的游戏中显示。见下文[换装](#makeover)。
- **快进与速度**：快进、快进速度、游戏速度、倒带和速度选项，包括场景速度、快进模式及快进音乐。见[快进](fast-forward.md)。
- **游戏玩法**：野生遭遇、可重复使用招式学习器、异色概率、NUZLOCKE 挑战、自动跑步、室内跑步和金手指。见[控制](controls.md)、[背包](bag.md)、[Nuzlocke](nuzlocke.md)和[金手指](cheats.md)。
- **屏幕**：画面比例、HUD、显示选项（状态栏、着色器、遮罩、轻量伴侣面板）、深色模式、帧率 / CPU，以及按设备显示的对战按钮、伴侣面板视图、伴侣面板按钮、交换屏幕或单屏。见[屏幕与显示](screen.md)。
- **伴侣面板**：对战提示、一键使用招式、对手个体值、标签栏、点击音效和调整。
- **控制**：游戏按键、快捷键、快捷菜单和触屏按键。见[控制](controls.md)。
- **应用**：提示、语言和帮助（本手册）。

每个选项详见[设置参考](settings-reference.md)。上屏也有自己的设置，包含更多选项及搜索框。

### 调整

`调整` 包含默认全开的开关：

| 选项 | 功能 |
| --- | --- |
| `队伍图标动画` | 队伍图标像游戏中一样跳动。 |
| `地图光标闪动` | 地图光标在两种大小之间闪动。 |
| `标签页动画` | 标签滑入；关闭后立即切换。 |
| `自动切换至对战` | 战斗开始时打开 `对战` 标签，结束后返回原页面。 |

![调整页面包含四个开关及各自的说明](shots/companion-settings-tweaks.png "设置 > 调整")

### 换装

`换装` 是设置顶部蓝框中的分组，包含 `主角外观`、`对手外观`、`文本样式`、`跟随宝可梦` 和 `昼夜变化`，为当前游戏带来新外观。只有至少一项功能适用时显示。

### 主角外观

想在 Emerald 中扮演 FireRed 的主角，或反过来？`主角外观` 可以换成另一款游戏的主角。地图上的行走、跑步、自行车、冲浪和钓鱼形象会改变，战斗背面、训练家卡照片及地区地图头像也会改变。伴侣面板的 `地图` 和 `训练家卡` 会跟随。

点击该行可看到可用主角方块，每个方块展示原地行走动画，名称下方标明来源游戏。第一个 `关闭` 是游戏自身的主角。点击方块即可换装。

PokeDaisy 不附带这些图片，而是从你自己的另一款游戏中读取。因此只显示曾在此游玩过或位于游戏库中的 FireRed、LeafGreen、Ruby、Sapphire、Emerald 或 Heart and Soul 的主角。每款游戏提供两位主角（Ruby 和 Sapphire 的外观与 Emerald 略有不同，Heart and Soul 提供 Gold 和 Kris），也可以选择当前游戏的另一位主角。Heart and Soul 的主角可用于其他游戏，但 Heart and Soul 本身保持自己的主角。找到可用主角前该行显示 `N/A`。默认 `关闭`，每款游戏各自记住选择。

存档保持原样。变化只存在于游玩时的游戏内存，存档仅记录你是游戏的两位主角中的哪一位。关闭后立即恢复原主角，在其他模拟器打开存档也保持原样。

> [!NOTE]
> `主角外观` 支持所有语言的 FireRed、LeafGreen、Ruby、Sapphire 和 Emerald 原版，以及 Emerald Kaizo、Emerald Legacy、Emerald Imperium 和 Ultra Violet。仅某游戏有的姿势（如 Emerald 的翘轮和潜水）会使用另一主角最接近的姿势。

也可以扮演自己的一只宝可梦。如果曾在此游玩或游戏库中有宝可梦可跟随的游戏（Heart and Soul、R.O.W.E.、Recharged Yellow 或 Emerald Seaglass），方块也会显示队伍中的宝可梦及其在该游戏中跟随时的行走动画。有多个此类游戏时，每只宝可梦只取自其中一个，方块会标明来源。选中后，它会在地图上代替主角（行走、跑步、自行车和冲浪），也会出现在训练家卡及战斗背面。只能选择前 386 种，其中少数体型最大的也不能选择。

### 对手外观

Ruby、Sapphire 和 Emerald 的对手是游戏的另一位主角。开启 `对手外观`（默认开启）后，对手也会换成所选游戏的另一位主角，在地图和战斗中显示：例如你穿 FireRed 的男主角，对手就变为女主角。关闭后即使你换装，对手仍保持原样。选择 `主角外观` 前显示 `N/A`；FireRed 和 LeafGreen 没有此项，因为对手不是主角之一。

### 文本样式

`文本样式` 将另一款游戏的文本框和字母带入当前游戏，例如在 Emerald 中使用 FireRed 圆角蓝白文本框，或在 FireRed、LeafGreen 中使用 Emerald 的蓝绿色文本框。人物对话、告示牌和存档询问都会使用该文本框，所有菜单字母也会改变。

与主角一样，文本框和字母来自你自己的另一款游戏，只有曾在此游玩或位于游戏库中时才显示该行。点击可在当前游戏外观（`关闭`）和另一游戏外观之间切换，不会修改存档。

> [!NOTE]
> 字母只能在相同语言的游戏之间替换（如英语 FireRed 和英语 Emerald），因为各语言字母不同。文本框支持所有语言。Emerald Imperium 保留自己的文本框，但使用另一游戏的字母。

### 跟随宝可梦

开启 `跟随宝可梦` 后，队伍首位宝可梦在地图上跟在你身后一步，跟随转弯、跑步和骑车，冲浪时等待。它由 PokeDaisy 叠加在游戏上，不改变游戏或存档；不会阻挡人物，也无法与其对话。穿过门后，迈出第一步时它会重新出现。

精灵图来自支持宝可梦跟随的游戏（Heart and Soul、R.O.W.E.、Recharged Yellow 或 Emerald Seaglass），与 `主角外观` 中可扮演的宝可梦相同。因此，在此游玩过或游戏库中存在这些游戏之一前，该行显示 `N/A`。默认关闭，已有宝可梦跟随功能的游戏不提供此项。

### 昼夜变化

开启 `昼夜变化` 后，地图跟随设备时钟：黎明柔和粉色、白天游戏原色、黄昏橙色、夜晚深蓝。只在行走时改变室外画面；文本框和菜单保持原色，建筑保持明亮，战斗外观不变，场景切换时平滑过渡。

适用于所有 GBA 游戏，但本身已有昼夜变化的游戏除外（Unbound、Heart and Soul、Elite Redux）。默认关闭；只改变画面，不改变游戏或存档。

### 提示

PokeDaisy 功能很多，有些容易错过。游玩约半小时后，带 PokeDaisy 花朵的小卡片会不时介绍尚未尝试的功能，如 `扩展画面` 的缩放和环顾、`快捷菜单`、`自动跑步` 或随时打开电脑。双屏时卡片显示在伴侣面板，避免遮挡游戏；单屏时显示在游戏顶部。

大多数卡片在功能正好有帮助时出现：例如长按 B 跑步一段时间后提示 `自动跑步`，连续几次野生战斗后提示 `野生遭遇`，招式学习器用完后提示 `可重复使用招式学习器`。

- **尝试**按钮会说明操作（如开启或显示），点击立即执行。
- **`不用了`** 表示该卡片不再出现。
- 不操作时，进度条结束后卡片自动消失，可能在很久以后再出现一次。

卡片只在场景行走时出现，不会出现在战斗、菜单或对话中。两张卡片之间至少间隔五分钟游玩时间，已使用的功能不会出现提示。可在任一屏幕设置的应用分组中关闭 `提示`。

### 语言

应用自身文字支持英语、日语、法语、德语、意大利语、西班牙语、简体中文以及葡萄牙语（巴西和葡萄牙分别选择）。`语言 (LANGUAGE)` 默认 `自动`，跟随游戏语言；手动选择后双屏立即切换。

设备设为葡萄牙语或简体中文时，`自动` 模式运行英文游戏也会使用设备语言。葡萄牙语下攻略正文保持英文；简体中文下已翻译的攻略显示中文，尚未翻译的保留原文并标记 `未译`。简体中文也翻译特定游戏的背包标签名称和前两世代战斗按钮。帮助提供简体中文页面及离线副本；尚未翻译的页面保留英文并标记 `未译`。

语言设置改变 PokeDaisy 的按钮、标签和提示等文字。简体中文还翻译标准属性名及已匹配的图鉴物种名称；无法匹配的图鉴名称保留游戏文本并标记 `未译`。昵称、招式和道具保持游戏原文。

## 关闭与重启

设置最底部横线下方有两个按钮：

- `关闭游戏` 返回游戏库。开启 `恢复游戏`（上屏设置中默认开启）时，下次可从离开处继续；关闭时，自上次游戏内存档后的内容会丢失，确认框会说明。
- `重新启动游戏` 重新启动游戏并从存储重新读取存档。游戏中未保存的内容会丢失。复制进存档却没有显示时可用此方法。

两者执行前都会确认。

双屏设备还提供 `关闭伴侣面板`，将面板屏幕交还 Android，游戏继续运行，可在该屏使用其他应用（开启 `交换屏幕` 时是上屏）。在游戏上按 BACK 可恢复面板；开启 `交换屏幕` 时 BACK 会让面板覆盖游戏，点击面板设置底部的 `打开伴侣面板` 可将其放回上屏。

> [!TIP]
> 不确定某一行的功能？设置最后的 `帮助` 会直接在下屏打开本手册。
