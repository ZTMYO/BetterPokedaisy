你可以从源码构建初版 Linux 程序，使用自己的 ROM 和存档运行 Game Boy、Game Boy Color 和 Game Boy Advance 游戏。对于受支持的英文第三世代正式版游戏，伴侣面板使用现有的跨平台核心；在这个基础版本中，其他游戏只有模拟功能。

依赖、原生及 TrimUI 构建、按键、存档路径和测试命令请参见源码仓库中的 `linux/README.md`。测试时请使用单独的数据文件夹；程序不会自动导入现有模拟器存档。

游戏和伴侣面板都按清晰的整数倍缩放适配屏幕，因此在 640×480、720×720 和 1280×720 的掌机上，文字大小大致相同。

游戏中按 Y 可在画面上打开快捷菜单：随时打开电脑、飞往到过的城镇、使用背包中的驱虫喷雾、上下自行车、关闭或重新开启野生遭遇、保存或读取即时存档、快进或打开伴侣面板。用方向键选中方块并按 A；B 用于关闭菜单。与游戏本身的菜单一样，飞翔需要队伍中有会该招式的宝可梦，并取得游戏要求的徽章。

HUD 在游戏场景上显示队伍、周围的小地图、喷雾剩余步数和精灵球，并避开游戏本身的文字。可在伴侣面板的 `SETTINGS` > `HUD` 中关闭 HUD 或其中任一部分。在 `SETTINGS` > `TAB BAR` 中可选择标签栏显示哪些标签，其余标签可从 `MORE` 打开。

按伴侣面板按钮可暂停游戏并打开面板。用方向键聚焦选项，A 确认，B 返回；肩键切换标签。游戏菜单中的保存、读取和退出确认框默认选中取消。

如需查看更多地图，可在伴侣面板的 `SETTINGS` 中将 `ASPECT` 设为 `EXPAND`：对于 Android 上支持扩展画面的游戏，场景会以与游戏相同的清晰缩放比例延伸到屏幕边缘。`ZOOM OUT` 会再缩小一级，显示更多内容。战斗和菜单仍按游戏原样绘制；开启 `AUTO ZOOM IN` 后，文本框也保持原样。

在支持 PortMaster 的系统（如 ROCKNIX、Knulli 和 muOS）上，可像其他移植游戏一样将 PortMaster 版本放入 `ports` 文件夹，并把游戏放入其 `roms` 文件夹。游戏过程中可以插入手柄。

这个早期版本尚不包含 Polished Crystal 伴侣面板、较长的概要或系统电源管理。早期构建曾在 Brick 和 Smart Pro 上运行，但这个拆分后的基础版本仍需重新进行设备测试；其他 Linux 掌机也尚未验证。
