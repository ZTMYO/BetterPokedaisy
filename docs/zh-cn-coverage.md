# 简体中文覆盖与核验清单

本清单记录已实现的范围和仍需完成的工作。翻译表存在条目不代表已用每个游戏版本、改版样本或实机逐项核验。

## 应用界面与语言

- `ZH_CN` 可在语言设置中选择，并沿用现有设置持久化机制。自动模式下，简体中文设备优先于英文 ROM，其他非英文 ROM 仍优先使用游戏语言。
- 现有应用翻译表的 1,352 条目均有非空中文；`scripts/check_translations.py --require-zh` 检查覆盖与占位符。这不证明所有硬编码的可见文字或动态内容都已纳入翻译表，仍需逐屏盘点。
- 已检查中文字体回退并在 Fusion Pixel 子集中补充 U+692A。`ChineseDeviceScreenshotTest` 模拟 Thor 1240×1080、Duo Lite 1280×960、RG DS 640×480 及单屏窗口 1920×1080，分别渲染设置、队伍、攻略和手册，共 16 张并已检查；RG DS 的 240 dpi 为估计值，单屏使用 369 dpi。截图只覆盖这些初始页面，不能验证全部长文本、弹窗、滚动、触控可达性或旧版 Android；2026-11-02 已在 AYN Thor 上对照并复测无界汉化版的五个队伍名称；其他页面和设备仍需实测。

## 内置攻略

- `scripts/check_zh_guides.py --require-all` 检查现有攻略翻译表及占位符；`GuideTranslationsTest` 审计已登记攻略的页面标题和静态数据并生成 `app/build/guide-zh-missing/` 报告。
- 审计依赖测试枚举范围：BOSS 动态队伍以空存档和地图组 0 至 80 取样。动态文本、其他存档状态和未来新增内容仍需检查。尚不能据此宣称所有改版版本或样本已核验。
- 无可靠译名的改版人物与地点可能保留原名。无法识别的攻略文字显示原文并标记 `未译`；已经包含汉字的原文保留。

## 游戏资料

- [版本级样本与核验清单](zh-cn-game-inventory.md) 从代码中的 66 个 GBA 改版配置生成，列出本次样本盘点及未核验状态；其他受支持游戏另列。该清单不代替每条资料的来源和版本核验。
- 图鉴物种名称表来自 [PokeAPI 固定提交的 pokemon_species_names.csv](https://github.com/PokeAPI/pokeapi/blob/6b8db7f3cb31cfaa37cb74e5c3edff124bcba5ce/data/v2/csv/pokemon_species_names.csv)，覆盖全国图鉴编号 1 至 1025。来源文件 SHA-256、许可及生成方式记录在 `scripts/gen_zh_species.py` 和 `NOTICE` 中。三处简体字修正的官方来源记录在生成脚本中；其余条目尚未逐条与官方来源独立复核。
- 图鉴只在全国图鉴编号与 ROM 原名称都匹配时显示该表译名；不匹配的名称（包括汉字名称）保留原文并标记 `未译`。玩家昵称不经该函数改写。该匹配仍需对每个支持的游戏和改版版本使用实际样本逐项验证。
- 标准属性标签在显示时翻译，逻辑使用原有属性标识。非标准属性和改版属性仍需逐项核验。
- 无界 2.1.1.1 新汉化版的信息页直接展示已解码的中文原文，进化和招式名称按 ROM 内部编号读取；未知或非中文内容仍标记 `未译`。测试覆盖超音蝠的中文说明和特性，以及部分物种和招式；AYN Thor 已实测信息、进化和招式页，其他条目仍需核验。
- 图鉴信息页中未经核验的正文和特性名称，以及图鉴招式列表中的招式名称保留原文并标记 `未译`；中文模式允许换行和滚动，以保留完整文字。
- 无界 2.1.1.1 新汉化 beta0.281 按 ROM 哈希复用现有汉字表：五个队伍名称与实机游戏画面逐字对照，前 33 个常见道具名与 ROM 条目对照；其余字符、图鉴正文和其他页面仍未逐项核验。昵称保留游戏原文。
- 地图后台加载按 ROM 文件哈希独立选择字符表，避免依赖游戏识别线程的时序；无界中文样本中的“冻土高原”和“贝林镇”已用实际 ROM 表测试，AYN Thor 顶部当前位置“贝林镇”已实测；地图页及其他地点仍需核对。
- 该无界版本的战斗物种和招式名按 ROM 内部编号读取，已用本地哈希匹配样本检查“铁哑铃”“冰宝”及三个战斗招式，并测试可唯一匹配的玩家昵称。AYN Thor 单打已实测名称及招式；其他条目和双打仍需核对。RG DS 模拟截图中招式威力与 PP 未完整显示，仍需调整。
- 该无界版本的背包名称从 ROM 道具表读取，并验证表内编号；前 33 项以本地哈希匹配样本测试，AYN Thor 上已检查当前立方包列表；其他条目和道具说明仍需核对。
- 背包详情栏中未经核验的道具说明保留原文并标记 `未译`，应用生成的操作提示不标记；长说明使用独立滚动区域，保留操作按钮空间。
- 队伍和战斗中的物种名称、招式、道具、特性、地点、图鉴描述及改版重写效果尚未全面适配或逐项核验；这些显示路径也尚未全部实现未知内容的 `未译` 标记。不能依据全国图鉴编号推断改版内部编号，也不能把未经核验的标准描述套用于改版。
- 本地样本的只读 SHA-1 盘点：Unbound 2.1.1.1 中文版、Radical Red 4.1 中文版、水银 FC 1.33、Quetzal Alpha 9 v0 中文版及 Team Rocket 中文版 3.04 与 `Poller.kt` 中的配置哈希一致。Elite Redux 2.65 beta2 中文调试版只在 `CjkTables.kt` 找到对应字表哈希，不能据此认定有匹配的运行配置。这些哈希检查只确认文件身份。可选测试 `TeamRocketCnDecodeTest` 已从本地西火中文样本的第 13 号道具表项解码出预期名称；其余条目的中文资料映射、游戏效果和动态显示仍未逐项验证。运行样本测试时以 `POKEDAISY_SAMPLE_DIR` 指定本地目录，ROM 不进入仓库。


## 帮助手册

- 24 页共享手册均已有中文页面；中文页与英文源文件通过 SHA-256 关联：英文变动后，旧译文会回退为标记 `未译` 的英文原文，直到重新校对。
- 网站中文页面、中文 API 和应用离线数据由同一份手册生成。应用内置已翻译页面的图片，搜索支持中文短语。现有插图是英文界面截图，尚需制作中文截图。
- 在 `website/` 运行 `node scripts/generate-zh-manual.js` 更新离线数据和已翻译页面的图片。`npm test` 检查链接、离线副本、图片散列、中文搜索及已有译文的源文件版本。

## 尚需完成的验收

1. 持续核对手册的界面标签、链接和操作，制作中文界面插图，并在英文源变化后重新校对译文及同步离线副本。
2. 盘点未接入翻译系统的用户可见文字和辅助功能标签，检查长文、弹窗、通知及错误提示。
3. 为每个支持的游戏和改版建立可追溯的资料及版本映射，按实际样本核验物种、招式、道具、特性、属性、地点和描述；登记无样本、无可靠来源及尚无译文的项。
4. 对 Thor、Duo Lite、小尺寸双屏、单屏及旧版 Android 检查字体、截断、换行和操作可达性，并记录实机覆盖情况。
5. 完成构建和回归测试。调试 APK 已在本地通过 `:app:assembleDebug --offline` 构建；这不代替设备安装和运行验证。
